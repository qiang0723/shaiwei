# 筛微阶段路线复盘与下一阶段裁决

- 复盘日期：2026-08-06（UTC+8）
- 复盘方式：主窗口证据核对 + 架构、研究方法、产品交付三个只读专项复盘
- 主裁决：`REORDER`
- 是否整体跑偏：`NO`
- 是否需要调整资源与顺序：`YES`
- 本文权限：只读审计与路线裁决，不授权任何新研究、外网、模型、回测、Web 或生产施工

## 1. 一句话结论

筛微的严格门禁、PIT、独立审计和生产隔离方向是正确的，本轮还实际阻止了一次历史前视污染；但近期
边际投入已经从“尽快拿到可信效果裁决”偏向“继续增加控制面和恢复工程”。最优动作不是降低标准，
而是冻结已经够用的治理底座、暂停无权威数据支撑的 M5 历史动态基本面支线，并把下一阶段集中到一个
成熟数据上的结果型研究批次。

因此不是推倒重来，也不是全面暂停，而是从“继续建设平台能力”重排为“用现有能力持续形成权威
终态”。

## 2. 当前事实基线

### 已经成立

- 中证800是当前唯一生产主策略；Top30 / Top20 模拟账户继续自然前瞻，不能用短样本比较优劣。
- 数据增量、信号、模拟组合、重放、告警和不可变证据链已经形成可运行闭环。
- P1资金流、F1/F2基本面、P2科创50基线、M4科创50残差等已经形成权威拒绝或停止证据；正式因子库
  仍为0，系统没有为了好看而虚构准入结果。
- M5多股票池工厂已具备提案、协议、release、输入身份、registry、runner、独立auditor和断网Docker
  隔离能力。
- 最新 M5 唯一真实谱系运行独立 audit PASS，23/23 冲突全部只能证明本地观察版本，历史PIT可恢复0
  组，权威 `NO_GO / BLOCKED_DATA`；候选和效果没有运行。

### 尚未成立

- 没有第二条可以配置资金的新策略。
- 没有正式准入的新因子。
- Top20相对Top30尚无足够可比前瞻账户日和真实调仓事件。
- 科创100/200和M5历史动态基本面都缺外部权威历史谱系，不是再写本地解析器即可解决。
- M5自动研究工厂还没有证明能提高“从协议到权威效果终态”的吞吐。

## 3. 没有跑偏的部分

以下能力必须保留，不能因短期没有新策略而放宽：

- 财报公告日、权威修订生效时间、本地观察时间分离；
- 成员、特征、标签、成交和成本的PIT/时钟纪律；
- protocol、release、输入、镜像和产物的内容寻址；
- DATA、ENGINEERING、EFFECT、FORWARD、PRODUCTION分层裁决；
- runner与独立auditor分离，负结果与错误尝试同样留痕；
- 一次性断网Docker和生产不可变scheduler隔离；
- 股票池身份、因子身份、模型身份和组合身份正交；
- 多重检验按研究家族全部尝试计数，不把池×窗口单元伪装成独立新想法。

这些设计不是形式主义。没有它们，本轮很容易把“2026年才抓到的版本”错误回填成历史时点已知版本，
并继续产生看似完整的因子和回测结果。

## 4. 已出现的路线失衡

1. **研究前工程多于效果终态。** 数据门、恢复协议、release和控制面持续增长，但正式因子准入仍为0。
2. **候选生成快于验证。** LLM和价量发现已积累较高尝试N，再扩大批量只会增加多重检验负担。
3. **把工程GO误当研究产出。** 数据可用、管线可跑和页面可看都不能替代扣成本后的策略增量。
4. **外部证据缺口被内部工程反复追逐。** M5、科创100/200当前缺的是权威历史版本或成员谱系。
5. **自动化可能早于稳定重复需求。** 当前先需要跑通少量结果型批次，不需要队列、常驻Worker或更多
   通用状态机。
6. **Web事实更新落后于证据。** `strategy_factory_v2` 最新快照生成于2026-08-05 17:08，尚未展示
   M5最新 `BLOCKED_DATA`；这是事实覆盖问题，不是视觉设计问题。

代码尚未成为不可维护的“屎山”，但已进入复杂度收益递减区：`m5_dynamic`约7,949行、
`gate_registry`约1,827行、M5专项测试约4,971行、M5文档34份。现在不宜在被阻断支线上继续叠加
runner/recovery变体，也不宜为整齐而大规模重构。

## 5. 综合裁决

| 范围 | 裁决 | 说明 |
|---|---|---|
| 中证800生产与自然前瞻 | `CONTINUE` | 不改模型和门槛，持续积累真实账户日与调仓证据 |
| 严格PIT、成本、审计和Docker隔离 | `CONTINUE` | 属于可信结果底座 |
| M5历史动态基本面支线 | `PAUSE` | 当前瓶颈是权威版本数据，不是本地代码 |
| M5 Registry v1 | `CONTINUE_AND_FREEZE` | 不迁schema，不扩成通用工作流引擎 |
| 多股票池策略工厂 | `CONTINUE_WITH_NARROWER_BATCHES` | 继续复用底座，但每次只跑一个可证伪机制 |
| LLM因子研究 | `ADJUST` | 用于假设、反例和审查；不作为进入效果门的硬依赖 |
| 科创100/200 | `PAUSE_DATA_DEPENDENT` | 等带公告、生效和修订身份的历史成员源 |
| Web | `FIX_TRUTH_PROJECTION_ONLY` | 补最新权威状态和阻断地图，不重做视觉、不加写控制 |
| 队列、Worker、一键研究、通用控制面 | `PAUSE` | 当前没有足够稳定的重复需求证明复杂度收益 |
| 权威历史版本补证 | `OPTIONAL_BOUNDED_GATE` | 先判断来源、覆盖、费用和时点字段，再决定是否立项 |

## 6. 下一阶段2—4周路线

  `fb134b91433003774945ab91f1dba02cf6daad5e`推送，旧release不得重跑。
- M5-2C继续阻断；不会自动进入外网补证、候选、效果或生产。

### 第1周：真身同步与结果批次冻结

1. 只修 Web 权威投影：显示M5 `BLOCKED_DATA`、23组仅本地观察、0组历史可恢复、策略
   `NOT_EVALUATED`和下一合法动作；不新增按钮、队列或写API。
2. 冻结一个“中证800模型/组合归因小批”协议：股票池、Alpha158、标签、窗口、成本、成交和组合
   口径保持不变，只比较冻结基线与最多两个事先确定的模型/融合结构；不做网格、多个seed或新增因子。
3. 该批的目标不是找最好模型，而是可证伪地判断当前瓶颈更可能在因子信息还是学习/组合结构。

### 第2周：完成一个权威效果终态

- 串行完成上述小批的数据身份、工程确定性和效果裁决；无论GO、REJECT或BLOCKED都必须归档。
- 看结果后不得改模型名单、窗口、成本、门槛或追加第三个变体。
- 模型比较沿用现有成本、回撤、前瞻隔离和多重检验纪律，但不把因子G1条文机械套用为模型门。

### 第3—4周：仅在前一批终态后启动跨池小机制

- 从科创50、自建中盘和自建小盘三个已有合法PIT池中选择一个独立经济机制家族。
- 最多3个固定公式，同一公式、参数和方向跨池一致；不再运行24/40个大生成批。
- 若3个候选均未在任何预注册池通过效果门，关闭该机制家族，不翻方向、不加第4个候选。
- LLM只提供经济解释和反例，候选与裁决仍由确定性合同控制。

### 并行低占用工作

- 中证800、Top30/Top20和每日生产自然运行；人工只处理异常和周度决策包。
- 对财报/指数权威历史版本源只做一次有界可行性判断；没有版本ID、发布/生效时点、修订关系和字段
  语义，就不进入采购或恢复施工。

## 8. 领先指标与停止条件

### 领先指标

- 每个研究批从冻结到权威终态的时间；
- 真实运行后协议/release返工次数；
- 进入数据门、工程门、效果门并形成终态的批次数，而不是候选数；
- Web权威状态相对Git/账本的延迟；
- Top30/Top20可比FORWARD账户日和真实调仓次数；
- 生产零人工修数、重放一致和异常恢复情况。

### 停止条件

- M5只有在23/23冲突都具备权威、唯一、完整的历史版本生效链后才允许新release；本地观察时间、
  latest/VIP/update flag、固定源优先或删样本都不能替代。
- Top30/Top20不足20个可比FORWARD账户日或不足2次真实调仓，不比较优劣。
- 连续两个独立研究批仍需在真实运行后修改协议、scope或release，暂停M5自动化并简化流程。
- 同一研究家族效果REJECT后，不换名字、调门槛或追加近似变体。
- Web投影与权威证据不一致时必须显示`NOT_READY`，不得拼旧快照给出结论。
- 只有至少两个独立研究批无需修改基础合同完成数据门和工程门，且未来6—8周确有至少3个重复批次，
  才重新评估M5自动研究工厂扩张。
