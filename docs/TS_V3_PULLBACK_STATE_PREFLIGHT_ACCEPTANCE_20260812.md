## 2. 真实事件分母

唯一一次断网画像形成 23 个“触达后恢复确认并检查紧邻下一开盘”的事件：10 个为合法入场事件，
13 个因下一开盘高于冻结周锚点而拒绝。用于未来效果的 2019—2024 固定区间只有 8 个合法事件，
分布在 5 个不同信号日：2020 年 3 个、2021 年 1 个、2022 年 0 个、2023 年 3 个、2024 年 1 个，
2019 年 0 个。

因此结果前冻结的四项门全部失败：

- 合法事件 8，低于最低 60；
- 不同信号日 5，低于最低 40；
- 2019—2024 并非每年不少于 3；
- 没有至少四个年度各达到 8 个事件。

2016—2018 与 2025—2026 只作结构诊断：全区间另有 2017 年、2025 年各 1 个合法事件，不进入
2019—2024 的效果分母。
