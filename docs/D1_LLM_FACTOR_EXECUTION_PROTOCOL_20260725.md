# D1-2B 首批真实 LLM 因子提案执行协议

## 1. 冻结裁决

本协议在任何付费 DeepSeek 请求、候选生成或发现期 RankIC 计算前冻结。D1-2A 的
`execution_authorized=false` 与 `$0.75` 草案记录永久保留，不回写；D1-2B 通过独立机器真身
`config/d1_llm_factor_execution_v1.yaml` 登记用户追加授权。

本次只授权 `d1-llm-dsl-v1-batch-001`：固定 `deepseek-v4-pro`、thinking/high、恰好 40 个完成响应；
D1 总授权额度为 `$10`，但本批硬熔断为 `$1`。未使用余额不能自动开启下一批，任何后续批次仍须新协议
和用户新指令。

## 2. 为什么 D1-2B 必须读取发现期数据

五个主题各 8 次，前 4 次为无反馈独立提案，后 4 次为有界变异。变异请求按既有提示合同必须携带同主题
全部更早尝试的 parser/sandbox、表达式复杂度、发现期覆盖率和 RankIC；因此本阶段只读冻结的
`2016-06-01—2018-12-31` 发现期。禁止读取 W1—W6、压力期、G1、前瞻结果和生产信号。

这不是回测裁决，也不证明策略有效。发现期结果只用于同主题受限变异和 40 次结束后的机械 Top2；人工经济
解释、W1—W6 与 G1 属于 D1-3，须另行授权。

## 3. 发现期口径

- 股票池：中证800动态成分；`.BJ` 必须为 0。
- 标签：与 Stage1 GP 冻结口径相同，`Ref(open,-11)/Ref(open,-1)-1`。
- 因子：只执行 D1-2A 白名单 DSL；不运行 LLM 返回的 Python、shell、文件或网络指令。
- 中性化：逐日申万一级 PIT 行业哑变量与对数总市值。
- 覆盖率分母：标签、PIT 行业和正总市值均有效的行；分子再要求候选因子有限。
- RankIC：逐日横截面中性化残差与标签的 Spearman 相关，再取日均。
- 每日至少 30 个横截面样本；少于 252 个有效日的响应照常计入 N，但候选拒绝。
- 发现期不根据符号翻转因子。40 次全部结束后，按 `|RankIC|`、覆盖率、复杂度、全局序号机械选前 2；
  少于 2 个可评价候选则 `PAUSE`，拒绝不递补。

## 4. 调用和费用边界

官方合同于 2026-07-25 再次核对：Pro 输入缓存命中/未命中和输出分别为
`$0.003625/$0.435/$0.87` 每百万 token。D1-2A 曾把官方版本名 `DeepSeek-V4-Pro` 与 Chat
Completion 响应 `model` 字段 `deepseek-v4-pro` 混成一个字段；本协议在任何付费响应前分列并更正，
原记录不回写。每次请求前按 16k
全未命中输入和 8k 输出保守预留；累计实际费用或下一次预留可能超过 `$1` 时，请求发出前停止。

HTTP 429/500/503 和连接建立失败最多有界重试 2 次；读取超时、写入不确定、悬空 STARTED 或 200 响应
不可解析均记 `BILLING_UNCERTAIN` 并停止，不自动重发。所有调用严格串行。

## 5. 安全与证据

- 运行使用独立不可变 Docker 镜像，根文件系统只读；不挂 Docker socket，不挂开发工作树。
- 应用层唯一允许的目标是 `https://api.deepseek.com/chat/completions`，`trust_env=false`；先完成 TLS
  主机名探测，再读取容器内唯一传入的 `DEEPSEEK_API_KEY`。
- 原始提示、响应、推理和发现期日序列只写项目内 Git 忽略的 `data/research/d1/`；密钥、Authorization
  和 provider 原始错误正文不得写入任何产物或账本。
- Git 只提交脱敏审计 ledger、结果 manifest、代码与文档。每个响应绑定 protocol、release、请求、
  响应、代码、数据、知识、发现期证据哈希，并与实验总账 1:1。
- D1-2A 的 attempt/transport v1 账本严格保持字节不变；D1-2B 使用独立 v2 账本扩展授权与发现期字段，
  不以“旧账本只有表头”为理由改写 append-only 历史。
- 生产 scheduler 的容器、镜像、启动时间和健康状态在执行前后核对；本协议不授权修改或重启生产。

## 6. 停止条件

价格或模型身份变化、secret 缺失、Git 未推送/工作树不净、输入哈希变化、`.BJ`、费用门、账单不确定、
usage 缺失、发现期执行器内部错误或生产 scheduler 身份变化，均立即停止。格式错、重复、DSL 拒绝和覆盖
不足属于已经完成的研究尝试，计入 40 和家族 N，不补位、不改提示、不调门槛。
