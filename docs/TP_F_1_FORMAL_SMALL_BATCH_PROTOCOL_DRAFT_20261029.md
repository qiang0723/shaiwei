## 1. 研究问题

中证800 PIT 成员，固定标签 t+1 开盘进、t+11 开盘出：**趋势质量 × 回踩质量的联合状态**，能否在 Alpha158 与行业/市值暴露之外提供稳定、非重复、扣成本后的增量信息？裁决权全部在 g1-v2。

## 2. 批合同（与 RF-1 相同处只列要点）

- **模型**：DeepSeek `deepseek-v4-pro`。执行时模型不可用即 `BLOCKED`，不静默换模型。
- **预算与规模**：至多 8 个完成响应、至多 3 个合格候选；单批熔断 $1.00，TP-F 总上限 $2.00（D4）。
- **调用纪律**：串行调用；失败和重复响应计入预算，不补位；每次尝试最多 2 次传输重试。
- **prompt**：冻结并以哈希绑定进 release。内容：TP-F-0A §2 的机制描述、候选语法、去重提示（不提供任何效果信息）。

## 3. 候选合同

1. **语法**：AlphaGen 安全 AST（TP-F-0B D1）。
   - 特征 `$open/$close/$high/$low/$volume/$vwap`；
   - 单算子窗口 ≤50 日，总回看（required backtrack）≤100 交易日；
   - ≤20 token、≤80 AST 节点（g1-v2 复杂度门）。
2. **规范表达式与经济陈述**缺一不可：陈述 ≥20 字，不得是占位。
3. **机制约束（D1）**：候选必须满足 TP-F-0B 冻结的联合状态签名，即同一规范表达式中，趋势分量与回踩分量各至少一个，且位于不相交的子树。
4. **身份去重**：以下任一命中即拒绝，并计入预算。
   - **规范 AST 去重**：与 RF-0B 封存注册表、TP-F-0B 扩展层（Alpha158 158 式、三本 LLM 账本、R3/R4/R5）中任一身份的规范 AST 相等。
   - **语义去重**：与 TS v5 语义签名或 TP-F-0B 普查中已有的 D1-v2 联合状态式语义等价。

## 5. 发现期选择与效果阶段

- **发现期**：g1-v2 区间 2016-01-01—2018-12-31。日有效 IC ≥252。
  - qlib 缓存起点前预热不足的日子（TP-F-0B：2016 年前 99 个交易日）候选值为 NaN，按 PIT 支撑自然剔除，不填充。
- **选择（D2）**：全部合格候选（≤3）在发现期计算 g1-v2 选择指标，机械取 Top1、Top2。方向在选择时冻结一次，取发现期 RankIC 的符号。不做参数网格。
- **家族 N（D3）**：g1-v2 的 DSR 按 TP-F 家族全部尝试计 N。逐尝试方差来自全部合格候选的发现期增量 IR；有效 IR 少于 2 个时，`valid_trial_increment_irs` 门如实失败。
- **效果**：Top1、Top2 依次进入 g1-v2 全部 15 门，读取区间与 TP-F-0B 画像一致：
  - 发现期；
  - W1–W6（2019–2024）；
  - 压力期 2017、2024-01/02、2026H1。
- **缺失处理**：沿用 g1-v2 既有管线。t+11 出场缺开盘 → 标签 NaN，当日该股不入 IC（TP-F-0B 计数 8,246）；申万 L1 缺失 → 不在 PIT 支撑内（15,375）。不另立口径。
- **记账**：裁决只写 `factor_admissions_v2` 与 `experiments`；不入因子库，不写 v1 准入账本。

## 7. 执行边界

- **网络**：只开 DeepSeek HTTPS LLM 通道。密钥只由 LLM 容器读取 DeepSeek key（不经人读）。其余容器断网、只读根、write-once，同 scope 不重跑。
- **审计**：每批独立审计。
- **禁止**：不碰模拟仓、scheduler、Web 或生产；不读 g1-v2 不读的区间。
- **序列（每步单独授权）**：
  1. 冻结推送；
  2. 工程：复用 `rf_1` 骨架与 `tp_f_0b` 签名/注册表，不复制；合成测试；
  3. 镜像内对抗 fixture；
  4. 等 R2-1R1 锁存，并经用户看过报告；
  5. 精确 scope → 用户逐字批准 → 单批生成 → 发现期选择 → g1-v2 判定 → 独立审计 → 验收。
