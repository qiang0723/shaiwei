## 4. 解读

- 与 v1 的对照：v1 在同类信号上 0.04/0.06 只过 2/5，原因是组合层点比较被选股噪声主导；v2 的逐日配对把两侧共同的市场与基线噪声消掉，
  同一机制下增量 t 随强度单调上升（中位 +3.0 → +11.9 → +20.0），噪声与基线复制稳定为负。
- 0.02 档 3/5、增量 t 在 2.80–3.47 之间跨越 3.0：发现期 RankIC 0.02 的增量处在门的检出边缘，0.04 起可靠检出。
- R2 纯因子组合各档增量为负或不足：因子单独的预测力弱于 Alpha158 基线——g1-v2 测的是“入库后相对基线的增量”，此结果符合定义。
- R4 低波：自身信号显著（t 6.1）但相对基线增量 t 1.92 未过 3.0，与 Alpha158 已含波动类特征一致；R3、R5 信号层即未过。
- 误放率上界：N1+N2 60 种子 4.87%、N3 30 种子 9.50%；所有种子共用同一数据、窗口与基线，评估不独立，上界是乐观近似，不能外推。
- 解释边界：终态只关于 g1-v2 在本数据、本窗口下的检出能力；R1 是含未来信息的合成信号，不代表任何真实因子能达到的效应量；
  标定通过不证明 g1-v1 的历史拒绝错误，也不预示任何历史候选在 g1-v2 下的结论。
