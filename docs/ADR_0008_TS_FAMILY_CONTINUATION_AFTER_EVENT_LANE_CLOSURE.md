# ADR-0008 · TS 家族在事件策略关闭后的继续研究边界

- 日期：2026-08-25（UTC+8）
- 状态：`ACCEPTED`
- 决策范围：TS 经济假设、既有失败身份与后继研究形态

## 1. 问题

TS-v5/v6、TS-B 与 TS-C 已形成不同层次的负面证据：既有事件驱动波段实现被效果门否决，TS-B 在
留出期出现牛市踏空，TS-C 的资格门与长期空仓设计冲突。部分文档因此写成“TS 支线关闭”，容易被
误读为“强趋势、右侧确认、高质量回踩”这一整类研究方向永久退役。

用户明确裁决：TS 大方向继续研究。需要在不改写历史 REJECT、不利用已读结果调参的前提下，区分
“具体身份关闭”和“研究家族继续”。

## 2. 决策

采用分层状态：

- `TS_EVENT_SWING_V3_V6 = CLOSED_REJECTED`：既有事件触发、稀疏持仓和对应退出规则永久关闭；
- `TS_B_HOLDOUT_IDENTITY = CLOSED_REJECTED`：不重跑、不换门槛、不复用留出期；
- `TS_C_QUALIFICATION_IDENTITIES = CLOSED_NOT_EVALUATED`：两版资格协议关闭，未证明策略有效或无效；
- `TS_ECONOMIC_HYPOTHESIS_FAMILY = ACTIVE_RESEARCH`：趋势、板块强度、个股右侧结构与回踩质量仍是
  长期研究主题；
- `TP_F_TREND_PULLBACK_FACTOR = GO_PREP_ONLY`：当前优先后继，把稀疏事件信念改写为每日横截面
  排序和篮子持有，避免硬开关导致长期空仓。

“方向继续”只表示允许提出新的、可证伪的机制身份，不表示原思路已经被数据证明正确，也不授权
DeepSeek、候选生成、效果读取、模拟仓或生产。

## 3. 为什么不直接重开旧 TS

旧证据已经否决了三个边际修补方向：固定参数邻点、入场质量硬过滤/排序子集、删除固定止盈。继续在
同一事件人群上调阈值，会把已读结果变成参数来源并扩大过拟合。

可以继承的只有结构性知识：

1. 稀疏事件与多重制度许可导致长期空仓，组合产能不足；
2. 回踩质量更适合作为连续排序信息，而不是连续叠加硬门；
3. 趋势市单笔经济性与组合超额必须分开评价；
4. 市场、板块与个股三层右侧逻辑仍需新形态独立验证。

不得继承旧收益数值来选择均线、ATR、止盈、止损、持有期、阈值或门禁。

## 4. 研究路线

TS 家族采用“轻量发现沙箱 + 严格正式验证”的双速通道，但同一时刻至多一个活跃机制分支：

1. 先完成当前 scheduler 跨进程锁与不可变发布，恢复可靠的自然证据链；
2. 完成 G1 阳性对照，证明正式因子准入门具备合理检出能力；
3. 执行 TP-F-0B 结果盲数据与身份预检，只检查字段覆盖、PIT、身份去重和可执行性；
4. TP-F-0B 通过后再冻结一个小批候选合同，候选/调用/费用仍须用户逐批授权；
5. 候选必须经过发现期、封存验证、成本、暴露增量、G1 和独立审计；通过后只允许独立模拟仓；
6. 只有真实前瞻证据成熟，才讨论自动调仓或生产。

若 TP-F 被身份重复、数据或效果门否决，TS 家族仍可提出下一种**实质不同**的机制形态，但必须先
说明变化轴与旧身份为何不同；不得回到旧事件策略做结果后参数搜索。

## 5. 与其他研究线的边界

- RF 隔夜跳空×日内反转是独立因子家族，不计作 TS 的继续版本；
- 科创池、资金流、Alpha158 与未来 LLM 因子工厂可为 TS 提供共享数据和去重事实，但不能替代 TS
  自身的经济机制与正式验证；
- 主策略、中证800生产信号和现有模拟账户不因本 ADR 改变；新 TS/TP-F 通过前不得覆盖主策略，可在
  未来以独立模拟账户并行。

## 6. 权威与回滚

本 ADR 补充 ADR-0006，不改写任何旧协议、账本、报告或 REJECT。若后续误把 `ACTIVE_RESEARCH`
展示为策略有效，查询和 Web 必须失败关闭或明确显示 `NOT_EVALUATED`。

若用户未来明确退役 TS 家族，可新增关闭裁决；在此之前，具体版本可以失败，研究方向保持活跃，但
不得绕过一次一个机制、完整尝试计数和正式验证门。
