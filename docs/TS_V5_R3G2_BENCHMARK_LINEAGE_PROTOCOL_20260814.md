# TS-v5 R3G-2 前置 H00906 总收益基准谱系协议

日期：2026-08-14（UTC+8）

状态：`RESULT_BLIND_BENCHMARK_LINEAGE_PROTOCOL_FROZEN`

机器真身：`config/ts_v5_r3g2_benchmark_lineage_v1.yaml`

## 1. 本节点只解决什么

R3G-1 已在 2021—2023 发现期机械锁定“突破后回踩”的一个锚点和两个邻居，并用 2024—2025 只做
冻结密度验证；2026-01-05 至 2026-08-11 只是部分年度观察。下一步在读取任何候选入场后收益前，
先确认中证800全收益指数 H00906 能否成为可审计的超额基准。

本节点不回答策略是否赚钱，不比较三个参数点，不读取候选收益、Alpha158 分数或排名，不训练、预测、
回测，不创建模拟仓，也不修改 Web、scheduler 或生产。数据门通过后，也只能另立 R3G-2 结果前效果
协议，不能直接看效果。

## 2. 时间范围为什么是 2019—2026

现行 TS-v5 选择和验证口径确实是 2021—2026，不是 2019—2021。基准采集从 2019-01-01 开始，是为
兼容仓库内已经冻结的 TS-v3 2019—2024 基准合同，避免以后为同一指数重复采集另一份历史；现行 R3G-2
仍只按以下互斥角色使用：

- 2021-01-04—2023-12-29：已发生的发现选择期；
- 2024-01-02—2025-12-31：已锁定稳定性期；
- 2026-01-05—2026-08-11：部分年度观察，不选参、不裁决。

2019—2020 只是兼容旧协议的基准数据，不得重新加入现行参数选择。

## 3. 权威来源与禁止替代

指数身份只认中证指数有限公司官方 000906 指数事实表，其中价格指数、净收益指数和全收益指数代码
分别为 `000906`、`N00906`、`H00906`。日线只认中证指数官方历史行情接口中显式请求
`indexCode=H00906` 的响应。

禁止用 `000906.SH` 价格指数冒充全收益指数；禁止本地加股息拼代理；禁止用无授权第三方页面覆盖官方
值。本次不需要 Tushare 或其他 secret。

## 4. 一次性采集与质量硬门

固定进行一次事实表请求和两次完全相同的历史行情请求。两份历史响应必须在写入前规范化后逐字一致，
否则停止。通过响应只允许形成不可变原始证据、日频 close 序列和脱敏 manifest。

硬门同时要求：

- 指数代码只能是 H00906，事实表和历史响应身份一致；
- 2019-01-01—2026-08-11 内日期集合与项目内既有 SSE 官方开市日完全一致；
- `(index_code, trade_date)` 重复、非开市日、未来日期和缺失开市日均为 0；
- close 有限且大于 0；接口若提供 OHLC，非空行必须满足 high/low 逻辑；
- 原始 PDF、两份 JSON、派生日表、报告和 audit 全部内容寻址且 write-once；
- 未来同源重抓若历史内容漂移必须 fail closed，不能静默覆盖本次快照。

官方公开接口若不可达、身份不符、覆盖不足或响应漂移，权威返回
`BLOCKED_OFFICIAL_SOURCE_NETWORK` 或 `NO_GO_H00906_LINEAGE_DATA_GATE`，不换代理救回。

## 5. 通过后仍然不能做什么

`GO_H00906_LINEAGE_DATA_GATE_ONLY` 只表示基准数据可用于下一协议，不表示突破回踩有效。通过后才允许
另立 R3G-2 效果协议，且只能纳入 R3G-1 已机械冻结的三个点，显式承认 2021—2023 已用于选择、
2024—2025 已用于密度稳定性检查、2026 部分年度不得选参或作最终裁决。策略效果与生产授权继续为
`NOT_EVALUATED` / `none`。
