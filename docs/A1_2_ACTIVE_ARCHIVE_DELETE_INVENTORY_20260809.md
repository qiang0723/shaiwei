继续让每个新研究批复制 release / recovery / audit 全套，会比单文件变大更早拖慢维护。

本轮 `SAFE_DELETE_NOW=[]`。原因不是没有冗余，而是 M6/M7 代码仍承担唯一历史 runner、auditor、批准
信封、镜像构建和失败解释职责，尚无专用 Git tag、完整归档 ADR 与隔离恢复演练。直接删除会用“主干
更短”换取“历史不能合法复算”，不符合筛微的结果可信目标。

却使用规模 segment，因而附加误报 1,449 行。该问题不影响轨 B 两项独立缺失硬门形成的权威 NO-GO，

冻结合同。不得在整理任务里修改旧 evaluator 后重算或覆盖历史报告。
