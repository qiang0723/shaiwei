# G8 产品比较篮子冻结规则

冻结日：2026-07-15。篮子成员见 `templates/fund_comparator.csv`；选择只使用产品定义和成立日，不使用冻结日前后的收益、排名、规模或基金经理表现。

## 纳入与排序

1. 标的为中证800或中证A500的境内股票指数增强基金，A类份额，人民币普通开放式；排除ETF、ETF联接、FOF、分级、定开及设有最短持有期的产品。
2. 业绩比较基准必须是对应指数收益率×95%加活期存款税后利率×5%；含其他权益指数或不同资产配比者排除。
3. 冻结日仍存续并开放日常赎回；已清盘产品排除。
4. 每个标的指数按基金合同首次生效日升序取前三只，同日按A类代码升序。结果固定为3只中证800和3只中证A500，共6只。

这套规则解释了为何不纳入更早的兴全中证800六个月持有指数增强（基准含5%恒生指数且有六个月最短持有期）和已清盘的民生加银中证800指数增强。

## 字段口径

- `固定运作费率合计` = 当前A类管理费率 + 托管费率；A类销售服务费为0。申购、赎回、交易、审计和信息披露等非固定费用不混入此列，后续收益比较直接使用已扣基金运作费用的复权净值。
- `合同跟踪误差上限` 是基金法律文件中的目标上限，不是历史实测跟踪误差；后续应从冻结日起用统一净值数据另算实际跟踪误差。
- `数据日期` 是本项目核对法律文件和产品页的日期，不冒充净值日期。
- 来源优先使用基金管理人官网或法定信息披露文件；每行保留可复核链接。

## 替换规则 R1

不因收益落后、排名变化、规模下降或基金经理变更而替换。只有基金清盘、A类停止提供可比净值，或业绩比较基准不再符合纳入条件时才触发：保留原行和历史，不回填；从触发日仍符合全部条件的产品中按“首次合同生效日、A类代码”升序补入，并新增一行记录替换日期和来源。任何替换不得重写冻结日前的篮子中位数。

## G8 使用边界

本文件只冻结成员和基础字段，不预先宣称任何产品优劣。G8 三年裁决使用冻结日起的 A 类总收益、
实际发生费税和同风险口径。风险归一化已于 2026-07-16 以 `g8-v1` 在
`docs/G8_SPEC.md`、`config/settings.yaml` 和 `src/shaiwei/evaluation/g8.py` 预注册；满三年前只允许
输出 `NOT_READY`，不得输出方向性结论。
