## 3. 程序

1. **复现门**：用 v1 中性化与 v1 方向规则重算，须复现配置所列对照物（逐日最大绝对差 ≤1e-6，日期集合一致）；不过的**整个家族**记
   `NOT_REEVALUATED`，正式执行中不得修补重试。
2. 复现通过后：PIT 中性化、逐日配对证据（证据 schema 2），按 g1-v2 全部 15 门判定；方向规则同 v1（发现期 RankIC 符号冻结）。
3. 家族 N：按 g1-v2 规格机械统计实验总账同家族全部尝试；每个候选本次各追加一行实验记录，N 变为 172 / 30 / 12 / 11；
   试验方差取本次重判写入的 `selection_increment_ir`。
4. 记账（D1）：新建只追加的 `ledger/factor_admissions_v2.csv`（经 `shaiwei.ledger.append_*` 唯一入口），报告写 `logs/g1-v2/`；
   v1 账本与 `logs/g1/` 一律拒写。
5. 每个候选只评一次；不改任何定义、参数、方向或数据快照；不重新挑选。
