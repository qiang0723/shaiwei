# D1-3A Top2 盲态对抗复核执行协议

## 1. 本阶段只回答什么

D1-2B 已用冻结的发现期规则机械锁定两条候选。本阶段只复核其公式真身能否支持可陈述、可证伪且
符合 PIT/次日开盘时钟的经济解释，并在不看任何后续结果的前提下执行结构冗余裁决。它不生成新候选，
不修改表达式、方向或窗口，不查看 W1—W6、压力期、G1、前瞻或生产结果，也不授权生产。

固定候选仅为：

1. `6ade2d0f6d103613`：`Std(Log(Div($high,$low)),20d)`，冻结方向 negative；
2. `3bf9d418202afc20`：`Std(Div(Sub($high,$low),$close),20d)`，冻结方向 negative。

候选身份、顺序和复杂度绑定
`config/d1_llm_factor_execution_manifest_v1.json` 及两份不可变原始响应/manifest；拒绝后不以第三名补位。

## 2. 已知盲态污染与处置

协议冻结前，主窗口在核对候选身份时误打印了候选 18 的完整发现期 manifest，因此见到了该候选的
发现期 RankIC 和覆盖率。没有查看候选 23 的发现期数值，也没有查看任何候选的 W1—W6、压力期、G1、
前瞻或生产结果。已暴露的数值不在本文、提示、账本或后续回传中重复。

因此冻结以下处理，不掩盖也不倒推：

- 8 份 DeepSeek 请求仍保持严格结果盲态，主窗口已见数值不会进入出站请求；
- 主窗口不得承担 D1-3 的最终人工解释闸裁决；
- 8 份机器复核完成只可进入 `GO_INDEPENDENT_HUMAN_GATE`，不能直接进入 G1；
- 最终人工闸必须由未接触发现期和后续效果数值的独立审查者完成，并另立 D1-3B 授权/冻结记录；
- 若独立审查未获授权或不能保持盲态，本目标停在人工闸前，不运行 G1。

## 3. 固定的八份 DeepSeek 复核

每个候选按相同顺序接受四个窄角色复核，总计恰好 8 个完成响应，串行执行：

1. `construct_validity`：公式实际测量的是日内区间代理的时间序列离散度，不能冒充 Parkinson 波动率
   水平或未经残差化的特质波动；
2. `economic_sign`：冻结负向符号必须由一致的行为或错误定价机制支持，“风险补偿更高所以未来收益
   更低”属于逻辑冲突；
3. `pit_execution`：当日 high/low/close 只能收盘后可用，最早在下一官方开盘形成仓位；
4. `redundancy_falsifiability`：只比较公式结构、经济构造和可证伪条件，不想象或引用业绩。

模型只能返回严格 JSON。格式错、截断或 schema 失败仍计入 8，不补发替代响应；只要不是 8/8 有效，
机器门即 `STOP_INVALID_REVIEW_RESPONSE`。DeepSeek 结论仅是对抗证据，不是准入裁判。

## 4. 结构冗余和人工闸

两式外层均为 20 日滚动标准差；小区间下 `log(high/low)` 与 `(high-low)/close` 是一阶近似的区间
代理。独立审查者须在不看效果时判断是否构成同一经济构造。若确认冗余，按结果前固定顺序只保留：

1. expression token 更少者；
2. 再比较 AST 节点更少者；
3. 再比较全局序号更小者。

被淘汰者记 `REJECT_STRUCTURAL_REDUNDANCY`。其余候选仍须同时通过公式身份/DSL、构造、方向、PIT、
可证伪性和冗余六项检查；任一失败即拒绝，不修改解释去迎合结果，不换候选。

## 5. 调用、费用与密钥边界

- 用户已指令开始下一目标并允许更多使用低价 DeepSeek；本协议将其收窄为恰好 8 份对抗复核。
- D1-3A 专项硬上限 `$0.25`，计入既有 D1 总授权 `$10`；D1-2B 已用 `$0.076626207`。
- 按 16k 全 cache miss 输入和 3k 输出预留，八次理论最坏费用 `$0.07656`，但仍保留 `$0.25`
  熔断以覆盖边界，不把余额解释为新任务授权。
- 只允许 `https://api.deepseek.com/chat/completions`，`trust_env=false`；先做 TLS 主机名探测，再读取
  容器中唯一传入的 `DEEPSEEK_API_KEY`。
- 密钥只保存在项目内 Git 忽略且权限为 0600 的 `.env`，不进入镜像、提示、响应、日志、账本或 Git。

## 6. Docker、证据和停止条件

`d1-review-live` 使用独立不可变镜像、非 root、只读根、无端口、无 Docker socket、无 `.env` 整体
挂载。历史 D1 数据和账本只读；唯一可写范围是项目内 `d1_3_reviews` 目录及两份 D1-3 专属追加式
ledger。原始请求、回复和推理保留在 Git 忽略目录；Git 仅跟踪脱敏 ledger、协议、代码、测试和终版摘要。

价格/模型变化、secret 缺失、Git 非冻结状态、输入哈希变化、出站禁词、费用预留越界、账单不确定、
usage/模型身份异常、不可恢复 transport 事件、证据哈希变化或生产 scheduler 身份变化均失败即停。
8 份复核结束前后必须核对生产容器、镜像、创建时间和健康状态不变，并进行无密钥断网幂等复跑。

本阶段终点最多为“允许进入独立人工闸”。只有独立人工闸通过的候选，才可另行冻结 D1-3B 的 G1
输入并运行完全不变的 `g1-v1`；本协议本身不授权 G1 或生产。
