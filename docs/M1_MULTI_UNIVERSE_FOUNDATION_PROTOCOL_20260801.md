## 1. 目标

把筛微从“中证800单股票池、单策略证据链”扩展为可审计的多股票池因子研究底座。M1-0只登记
股票池身份、PIT证据等级、当前允许用途、跨池评价键和失败关闭规则，不采集新数据、不计算因子、
不训练模型、不查看IC/收益/回撤，也不创建新的前瞻或生产账户。

后续研究结构固定为：

`股票池身份 → PIT数据门 → 因子发现 → 因子级跨池验证 → 少量模型组合 → 独立模拟账户`

数据可行、因子有效、模型有效、前瞻有效和生产授权必须分层裁决。

## 3. 既有结论的继承边界

- P2-2C只拒绝科创50的既有`Alpha158 + LightGBM + Top10/n_drop2 + 10日调仓`基线，不拒绝科创50
  股票池，也不拒绝未来独立预注册的因子家族；旧P2的窗口、模型、TopK和组合参数不得自动继承或被
  偷偷微调。
- P4-0只阻断官方科创100历史成员谱系与PIT构造，策略仍为`NOT_EVALUATED`；不得用自建中盘池的
  结果替代官方科创100结论。
- 科创200与科创综指尚未完成本项目数据门。官方发布、编制方案或指数日线存在，不等于历史成员PIT
  已可用于回测。
- 中证800仍是唯一生产主策略；M1-0不改变任何现有信号、模拟账户或生产调度。

## 4. 机器合同

新增严格YAML注册表和独立只读校验器。注册表必须：

1. 为每个股票池登记唯一`universe_id`、身份类型、官方代码或自建身份、PIT状态、证据文档和当前允许
   动作；
2. 对官方池和自建池使用互斥身份，禁止自建池声明官方指数代码、官方成员数或官方品牌别名；
3. PIT未通过的股票池不得获得因子计算、模型、历史策略、前瞻或生产权限；
4. 只有`csi800-pit-v1`可保留既有生产权限，注册表不得授予任何新生产权限；
5. 全部股票池显式排除`.BJ`；证据路径必须是项目内相对路径且真实存在；
6. 注册表相同输入生成稳定的canonical SHA-256和确定性摘要；
7. 未知字段、重复ID、重复官方代码、非法状态组合、证据缺失或跨层越权全部fail closed。

校验器不读取`.env`、行情、账本或研究结果，不导入生产配置，不具备网络和写数据能力。

## 5. 因子跨池裁决合同

- 因子定义身份与股票池分离；同一精确公式在不同股票池仍保留同一`factor_id`。
- 评价身份至少包含：`factor_id`、`factor_version`、`universe_id`、`benchmark_id`、`label_id`、
  `horizon_id`、`neutralization_id`、`window_set_id`、`cost_policy_id`和`decision_rule_version`。
- 准入结论必须绑定`universe_id`；某因子在中证800通过，不代表在科创50/100/200通过，反之亦然。
- 一次生成计一次全局研究尝试；把同一候选投到多个结果前预登记股票池属于多个评价单元，不得冒充
  多个独立生成尝试，也不得把评价单元数机械当成独立假设数。
- 目标股票池必须在查看该候选对应结果前冻结；结果后增加、删除或改名股票池视为新研究协议。
- 只有每个股票池独立通过覆盖、PIT、RankIC、稳定性、换手、成本、容量、压力期和多重检验门，才可
  获得该股票池的因子准入；任何历史GO也不自动授权前瞻或生产。

## 6. 后续顺序

1. **M1-1 科创50新因子研究**：科创50是当前唯一数据与工程证据均已完成的科技股票池；须另立结果
   前协议，登记既有P2负面证据和新的研究尝试预算，不调用旧P2参数调优。
2. **M1-2 科创200数据门**：先核验官方首批、规则版本、历史调整谱系、指数日线和二级集合对账；
   数据GO前不计算因子。
3. **M1-3 科创板规则型研究池**：在全量股票历史覆盖审计后，冻结全市场/中盘/小盘的PIT规则；不得
   把规则池冒充官方指数。
4. **P4恢复**：只有取得带发布时间、版本和修订语义的科创100官方历史成员源后才恢复官方臂。
5. **跨池验证与模型**：先冻结候选和评价矩阵，再做因子转移性验证；只有因子级证据通过后才讨论
   线性组合、LightGBM或其他模型。
