  仅 1 行，且该行最终无可用连续对；
- 唯一缺对为 `2018-05-31 / 000939.SZ`：形成日前可得的 2016 年三表共同期存在，但其 2015 年利润表

  既不能倒灌 2015 修订，也不能提前使用 2017 披露，保持空值是正确 PIT 行为。

## 6. 运行故障与边界说明

构建阶段曾把长于 30 秒的 Docker 会话误判为结束，造成多个同名构建尾部并存；一个空 release 参数的
迟到构建覆盖了正确镜像标签。它未产生新的研究裁决，但使第一次幂等复跑在 `git_head()` 处失败。
随后停止并发构建、用完整 `git rev-parse` 哈希串行重建，运行前确认 release 为
`795993a92a63daac22961e9541d0e022eb7372fc`，再完成第二遍。后续长 Docker 构建必须持续轮询唯一执行
会话，并在研究运行前定向核对 release 字段。

定位时曾输出该一次性研究镜像的完整构建环境列表，违反“只打印定向字段”的操作纪律；列表仅包含
Python/路径/构建参数等非敏感常量，不含 `.env`、Tushare、飞书或 DeepSeek 凭据，也不是生产容器环境。
后续 Docker 身份复核恢复为只输出容器 ID、镜像、创建时间、健康和单一 release 字段。

最终 F2 镜像 ID 为 `sha256:40289a84cdd5c2d4d121b8d8851a2fb0b55ec327969000e397076ac093303640`。
正式运行断网、只读根，仅 F2 忽略目录可写；未读取 `.env`，未改原始数据、账本、scheduler、生产配置、
模拟仓或 Web。
