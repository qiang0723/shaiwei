# Web 1.0 低保真与可点击原型方案（v1.0）

> 线框只使用示例占位符。`BACKFILL`、`FORWARD`、哈希与状态均必须在原型中明确标注为示例，禁止复制生产证据到外部工具。

## 1. 全局框架

```text
┌ 筛微 ───────────────────────────── as_of [日期]  证据 [抽屉] ┐
│ 总览                                                         │
│ 因子工厂              ┌──────────────────────────────────────┤
│ 模拟组合              │                                      │
│ 股票池/信号           │ 页面标题  状态  数据截至 / 生成时间   │
│ 模型/回测             │                                      │
│ 数据质量              │ 主内容：结论 → 趋势 → 诊断 → 明细     │
│ 系统运行              │                                      │
└───────────────────────┴──────────────────────────────────────┘
```

证据抽屉在所有页面保持同一结构：身份 → 新鲜度 → source refs → 完整哈希 → 复制。没有“打开文件”“编辑”“重跑”。

### 1.1 视觉层级标注

低保真原型进入视觉稿时按以下强弱关系处理：

- L1 第一焦点：页面状态/行动结论或主结果图，只能有一个；
- L2 第二焦点：解释 L1 的 1–2 个诊断区域；
- L3 支撑信息：明细表、时间线和异常列表；
- L4 证据身份：时点、版本、哈希和来源，不抢占主内容但始终可达。

所有页面使用同一 8 px 间距系统、同一数值精度和状态组件。视觉评审不仅看单张画板，还必须连续查看“总览 → 组合 → 账户日”和“总览 → 信号 → 证券详情”，确认重点不会在下钻过程中漂移。

## 2. 总览

```text
┌ [NOT_READY] 前瞻账户日尚未形成  截至 07-22  任务 PASS / 通知 PASS ┐
├ 今日行动 ─────────────┬ 前瞻验收 ─────────┬ 风险/异常 ──────────┤
│ 非调仓                │ 0 个 FORWARD       │ 无阻断异常           │
│ 下一执行日：待证据    │ 重放：PASS         │ 通知与任务分列       │
├ 前瞻模拟仓 vs 中证800（最后 BACKFILL 日=1；无 FORWARD 则空态）─┤
│ [FORWARD 专属归一化净值双线]                                   │
│ [前瞻累计净值差零线]             [同范围回撤负值面积]           │
│ 全账户审计历史：BACKFILL 灰虚线 → FORWARD 主色实线 [展开]       │
├ 执行诊断 ─────────────────────────────────────────────────────┤
│ 实际持仓 | 现金比例 | 成交率 N/A | 累计费用 | 当前回撤          │
├ 证据链：数据 → 门禁 → 模型 → 信号 → 对账 → 模拟仓 → 重放       │
└ 异常清单（仅异常；点击进入系统运行）───────────────────────────┘
```

点击：组合曲线 → 模拟组合并定位账户日；调仓卡 → 信号；异常 → 系统运行；任一哈希 → 证据抽屉。

## 9. 状态原型矩阵

每个首期页面必须制作以下独立画板/本地路由状态：

| 状态 | 总览 | 模拟组合 | 信号 |
|---|---|---|---|
| 正常 | PASS + 新鲜证据 | FORWARD + 重放 PASS | 调仓/非调仓各一 |
| 未就绪 | 0 FORWARD | BACKFILL 仅工程回放 | 信号尚未生成 |
| 过期 | 数据时钟滞后 | 估值 STALE | 对账尚未到执行日 |
| 警告 | 任务 PASS/通知 WARN | 非阻断估值警告 | 部分目标受阻 |
| 失败 | 证据断链 | 重放 FAIL | `.BJ` 或哈希不一致 |
| 空态 | 无登记快照 | 范围无账户日 | 范围无信号 |
| 请求错误 | 稳定错误码 | 可重试/不可重试 | 可重试/不可重试 |

## 10. 可点击原型路线

原型建议用仓库内本地静态页面实现，但必须另立代码目标；本轮只冻结路线：

1. `/overview` → 点击组合图进入 `/paper?date=...`；
2. `/overview` → 点击今日行动进入 `/signals?signal=...`；
3. `/paper` → 点击账户日打开 `day-ledger` 抽屉；
4. `day-ledger` → 点击订单打开订单/成交证据；
5. `/signals` → 点击证券打开信号详情抽屉；
6. 任一状态/哈希 → 全局 `evidence` 抽屉；
7. 任一异常 → `/system-runs?run=...`；
8. 移动端保持相同信息和操作，不以隐藏替代重排。
9. `/factors` → 因子目录 → `/factors/:id?version=...` tear sheet → 判决历史/实验/证据；
10. 因子详情选择“对比”，最多加入 3 个可比版本；后端判定不可比时不生成对比图。

验收任务：键盘从跳转链接进入主内容；Tab 顺序符合视觉顺序；Esc 关闭抽屉并把焦点返回触发点；浏览器后退恢复路由和 `as_of`；刷新后不会把旧缓存显示为最新。
