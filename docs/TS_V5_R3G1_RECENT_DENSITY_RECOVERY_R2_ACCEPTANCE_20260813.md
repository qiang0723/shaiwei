原 R3G-0 文案沿用了 TS-v4 的 2019—2021 发现期，但这不是本地数据只能到 2021。冻结输入实际覆盖
至 2026-08-11。R3G-1 在任何密度读取前改成以下互斥角色，覆盖用户要求的 2021—2026，同时避免把
最近数据全部拿来选参数：

  `NOT_FOR_SELECTION_NOT_FOR_VERDICT_PARTIAL_YEAR`，不参与选择或裁决。

六年不得合并成一个参数选择样本，也不得把 2026 的非完整年度按全年门槛折算。

## 2. 首轮全零为什么失效

首轮报告、零行事件文件和独立审计永久保留，但静态合同追踪确认两个公共接线错误：角色流没有投影
次日执行合同必需的 `raw_open`，并且 `has_bar` 错把官方交易日存在当作个股行情存在。前者会把每个
已确认状态在次日执行时统一取消。因此首轮 `STOP_NO_RECENT_DENSE_MECHANISM` 降为
`INVALIDATED_BY_COMMON_EXECUTION_PROJECTION_DEFECT`，不能作为策略或密度结论。

R2 只补 `raw_open = adjusted_open / positive_adjustment_factor`、以个股行情 JOIN 命中定义
`has_bar`，并让缺少必需字段直接失败关闭。六机制、431 点、参数、密度门、选择算法、输入和三段时间
角色均未改变。原产物哈希在 R2 后仍为：

- profile `51d0bcdc...963a`
- events `3b681836...70da`
- audit `6a284581...0b15`
