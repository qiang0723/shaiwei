## 1. 本节点解决什么

R3F 已得到六份通过严格合同、互不重复的 DeepSeek 提案，但“合法 JSON”不等于“可以直接回测”。R3G-0 先把六种入场机制固定为唯一、逐日、PIT（只使用当时已知数据）的状态机语义，并用合成和对抗样例证明：相同输入必得相同事件、同日取消优先于确认、任何未来字段和隐式修补都会失败关闭。

本节点只做工程语义和候选登记，不读取证券、行情、收益、Alpha158 分数、验证集或锁定测试集；不调用 DeepSeek 或其他外网；不训练、不回测、不改模拟仓、Web、scheduler 或生产。

通过时只允许主控另立“无收益事件密度投影”协议，不能据此声称策略有效。

## 3. 继承边界

六种机制仅替换“什么时候入场”，不推翻已有 TS 产品约束：

- 继承 TS-v3 的完整月线/周线右侧结构、当日大盘/上市板块/行业门、PIT 行业与市值、流动性和可交易资格；
- 资格在触发、确认和下一合法开盘执行时均重新检查；等待期丢失大盘或行业门即永久取消；
- 只使用已完成周/月和当前收盘时已经形成的日线字段；ATR、均线、成交额中位数、相对强度峰值与分位阈值均排除当前 bar；
- 每只股票同时最多一个活动 episode；触发时冻结 reference、threshold、结构止损和参数；同一 episode 不重复出事件；
- 收盘后确认，紧接的下一合法官方开盘执行；执行失败不在同一 episode 重试；
- Alpha158 值、排名和结果不得参与本节点或下一密度节点。

## 4. 六种机制的唯一操作化

共同状态为 `IDLE → ARMED → CONFIRMED → NEXT_OPEN_EXECUTION`，或在任一等待日进入吸收态 `CANCELLED`。同日先计算取消，再计算确认。触发收盘的等待龄为 0；此后每个官方开市日收盘加 1；等待龄 0 至 M（含 M）可以确认，严格超过 M 时先取消，因此同日触发和首次确认在 N=1 时合法。

1. 波动自适应回调
   - 参考线：上一完整周复权 VWAP；ATR 为此前 L 个日 bar 的真实波幅均值，不含当前 bar。
   - 触发：当日最低价落在 `[参考线-M×ATR, 参考线]`。
   - 确认：连续 N 日收盘不低于参考线。

2. 周结构分位回调
   - 参考线：上一完整周低点加 Q 倍周内振幅。
   - 触发：当日最低价不高于参考线。
   - 确认：连续 N 日收盘不低于参考线。

3. 突破回踩
   - 突破线：最新完整周之前 L 个完整周的最高价；最新完整周收盘必须严格站上该线。
   - 触发：最低价不高于突破线加 T×ATR，且收盘不低于突破线减 T×ATR。
   - 确认：连续 N 日收盘不低于突破线。

4. 均线恢复
   - 参考线：此前 L 个日收盘均值，不含当前 bar；容忍带为 T×20 日 ATR。
   - 触发：最低价不高于参考线加容忍带，且收盘不低于参考线减容忍带。
   - 确认：连续 N 日同时满足收盘严格高于参考线、严格高于前一有效日最高价、成交额严格高于此前 20 日中位数。

5. 缩量收敛后放量
   - 前提：最新完整周的周振幅在截至该周的 L 个完整周中经验分位不高于 Q。
   - 参考线：最新完整周最高价；合格计划周首个日 bar 进入等待。
   - 确认：连续 N 日收盘严格高于参考线，且当日成交额不低于此前 20 日中位数的 R 倍。

6. 行业相对强度回调
   - 相对强度：股票 L 日毛收益除以当时 PIT 行业等权篮子 L 日毛收益；分母缺失或非正即不可评估。
   - 峰值：此前 L 日相对强度滚动峰值；阈值：此前 L 日正相对强度回撤的经验 Q 分位，均不含当前 bar。
   - 触发：当前相对强度回撤不低于阈值；恢复线固定为峰值×(1-阈值)。
   - 确认：连续 N 日相对强度不低于恢复线。

结构止损统一为触发时最新完整周低点×0.98。候选声明的 `NEXT_OPEN_ABOVE_REFERENCE` 只在下一开盘检查；声明 `LIQUIDITY_GATE_LOST` 时，等待期流动性丢失亦为吸收取消。

## 5. 参数网格只验证工程，不搜索效果

小数参数使用包含两端点的精确 Decimal 等距点；整数参数使用包含两端点的等距唯一整数，点数受整数区间可取值数量限制。因此编译器给出的 `search_points_maximum` 是上限，不保证实际唯一点数与上限相等。

六候选最大预算分别为 81、125、81、81、32、81；去除整数重复后的有效点数分别为 81、75、81、81、32、81，共 431 个。R3G-0 只在合成数据上验证这 431 个组合可生成、唯一、确定性一致，不读真实数据。

- 每种机制用固定排序选一个密度锚点，再选归一化曼哈顿距离最近的两个合格邻点；不允许人工挑点；

## 7. 架构与证据要求

沿用 ADR-0006 的“LLM 只产出非权威候选、确定性编译器掌握权限”边界，不新增服务、依赖或公共账本 schema。实现限定为：

- 一个冻结输入/网格模块；
- 一个纯函数状态机模块；
- 薄的验收入口与独立审计入口；
- 单独的 `network_mode: none` Docker profile，仅精确只读挂载 R3F 证据和账本，只写 Git 忽略的 R3G 证据目录。

报告只保留候选编号、机制、参数、合同身份、状态迁移计数和哈希；不提交 LLM 自由文本、reasoning、行情、证券、结果或凭据。

必须通过：六候选从不可变 content 重新编译且 fingerprint/signature 完全一致；431 个网格点数量和唯一性一致；六机制正常路径；未来字段、当前 bar 偷看、缺字段、重复 episode、同日取消/确认冲突、等待超时和非法下一开盘的对抗 fixture；二次复跑逐字节一致；独立审计全量重算；全仓测试、Ruff、架构检查、敏感信息检查。

全部通过的唯一裁决为 `GO_R3G_DENSITY_SCOPE_PROPOSAL_ONLY`；任一失败为 `STOP_R3G_EXECUTABLE_SEMANTICS_GAP`。
