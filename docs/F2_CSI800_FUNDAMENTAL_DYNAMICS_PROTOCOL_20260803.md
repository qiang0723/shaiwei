# F2-0 中证800基本面动态因子数据/特征门协议（结果前冻结）

冻结时间：2026-08-03 12:32:08（UTC+8）。机器真身为
`config/f2_csi800_fundamental_dynamics_v1.yaml`；本文只解释研究边界，不覆盖机器协议。

## 1. 本目标只回答什么

F2-0 只判断：现有不可变 Tushare 财务报表、交易日历和中证800历史成员真身，能否在严格 PIT
语义下构造连续两个可比年度的六项“基本面变化”特征，并达到预先冻结的数据覆盖门槛。

本目标不读取标签、预测、RankIC、收益、回撤、排名、持仓或任何既有候选的效果；不训练模型、不回测、
不生成信号、不调用 DeepSeek，也不改 scheduler、生产中证800策略、模拟仓或 Web。

## 2. 为什么不是对 F1 的结果后救活

F1-1 的六项静态水平因子已权威 `REJECT`，正式库插入为 0。本协议永久绑定该裁决及其 manifest 哈希，
禁止再次计算或评估那六项静态公式，禁止换方向、调权重、改窗口或以别名重跑。

F2 研究的是另一种经济机制：公司基本面在连续年度之间的变化，而不是某一年度的绝对水平。六项公式
固定为资产增长、收入增长，以及营业利润、归母净利润、经营现金流和现金余额相对平均资产的变化。
若未来任何效果被读取，F2 六项各计一次新尝试，并与 F1 的六次合并披露为累计 12 次；窗口、成本场景
和诊断单元不得伪装成独立试验，也不得因 F2-0 数据门结果追加第七个公式。

## 3. 严格 PIT 与连续年度定义

- 每个财务分量只允许使用形成日当日已经可得的版本；可用日为 `f_ann_date` 后首个开市日。
- 先在同一证券、同一 `end_date` 内按最新已知公告日、报告类型和更新标记确定版本，再跨三张表求共同期。
- 当前期与前一期都必须分别在利润表、资产负债表和现金流量表拥有完全相同的年末 `end_date`；两期必须
  精确相隔一个日历年，禁止把不同比例或不同报告期拼成一个特征。
- 选择截至形成日最新的“当前期 + 精确上一年度”共同可用对。若更晚年度尚未形成完整连续对，可以继续
  使用此前合法连续对，但必须单独诊断，不得把未来披露倒灌到早期形成日。
- 特征联合可用日取两期全部组件可用日的最大值，必须不晚于形成日。
- 禁止 `fina_indicator`、当前成分回填、插值和任何未来修订回填。

## 4. 六项冻结公式与方向

方向在数据门阶段只登记、不用于计算或裁决：

1. 资产增长率：`assets_t / assets_t-1 - 1`，预期负向；
2. 收入增长率：`revenue_t / revenue_t-1 - 1`，预期正向；
3. 营业利润变化：年度差额除以两期平均总资产，预期正向；
4. 归母净利润变化：年度差额除以两期平均总资产，预期正向；
5. 经营现金流变化：年度差额除以两期平均总资产，预期正向；
6. 现金余额变化：年度差额除以两期平均总资产，预期正向。

分母必须有限且严格为正；无效或非有限输出置空。F2-0 禁止 winsorization、中性化、方向翻转或组合。

## 5. 结果前数据门

质量期自 2018-05-02 起，必须至少有 90 个自然月末形成日；每个形成日中证800成员数须为
700—900，`.BJ=0`。主键重复、两期各自混期、非连续年度对、未来可用数据、财报身份冲突和质量期无
连续年度对均须为 0。六项特征的总覆盖率各不低于 85%，最差单形成日覆盖率各不低于 75%。

所有门均通过只能裁为 `GO_F2_FUNDAMENTAL_DYNAMICS_DATA_FEATURE_GATE_ONLY`，含义仅是可以另立
F2-1 效果协议；任一门失败即 `NO_GO_F2_FUNDAMENTAL_DYNAMICS_DATA_FEATURE_GATE`。两种裁决下
`strategy_effective` 都必须保持 `NOT_EVALUATED`，生产授权均为 `none`。

协议文件必须先于任何 F2 特征构建提交并推送。实现须拆分契约、连续年度配对、公式和薄编排，新增

未变化、全仓测试与脱敏检查通过。
