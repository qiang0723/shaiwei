## 2. 待裁决（冻结前必须定）

**D1 · 候选表达路径与回看上限**（TP-F-0A 机制含"月/周结构"，与现行语法冲突）

现行 AlphaGen 语法（`alphagen_expression.py`）只允许 `$open/$close/$high/$low/$volume/$vwap`，单算子窗口 1–50 日；G1 研究数据
回补 100 个交易日；qlib 缓存始于 2016-01-04，而 g1-v2 发现期自 2016-01-01 起。

| 选项 | 内容 | 代价 |
|---|---|---|
| **A（建议）** | 沿用现行语法与 G1 管线：单算子 ≤50 日、总回看 ≤100 交易日；"月结构"以 ≤100 日近似（约 5 个月） | 无新语法；复用 LLM 小批、规范 AST 注册表、PIT/shift 哨兵与 g1-v2 判定；更长的趋势持续度不在 TP-F v1 范围 |
| B | 为 TP-F 家族把总回看放宽到 ≤260 日（参照 G1 正控 R5 的专用研究数据） | 新语法版本与工程；2016 整年落入预热，发现期实际只剩 2017–2018 |
| C | 人工冻结的原始面板参数族（如 F1/F2），不调 LLM | 偏离 ADR-0008/TP-F-0A 的"RF-1 同规格小批"；身份去重需另建规格层 |

**D3 · 输入与画像期间**：**建议**绑定 RF-0C 同源的 TS v3 R3 冻结 manifest（`c2206a6f…`，11 层齐全，至 2026-08-11）与 qlib 缓存

外加 D1 定的预热。备选：沿用 RF 的 2019-01-02—2025-12-31（不覆盖发现期与 2026H1 压力期）。

**D4 · 身份注册表扩展与去重规则**（建议如下）：

1. RF-0B 封存注册表（`identity_registry.json` sha `d3777d7a…`：D1-v2 40、M1 40、M3 24、G1 29 身份、Alpha158 158 式）逐字节复现，不等即失败关闭；
2. 扩展层（只读身份列）：G1 正控公开因子 R3 反转、R4 低波、R5 动量作为参照身份（TP-F 不得是同义动量/反转）；TS v5 四批 28 次 LLM 尝试的
   `semantic_signature`/`candidate_fingerprint` 作为同信念语义层；g1-v2 重判无新身份（与 G1 21 定义同一）；
3. **联合状态签名**（确定性 AST 规则，冻结时定窗口界）：趋势分量 = 价格特征相对 ≥20 日锚（Mean/EMA/WMA/Med/Max/Min 或 Ref）；

4. 判定：若 **Alpha158 已含联合状态表达式** → `REJECT_DUPLICATE`（交点已在基线内）；既有 LLM/G1 身份命中只报告计数，作为正式批的逐候选去重参照。
