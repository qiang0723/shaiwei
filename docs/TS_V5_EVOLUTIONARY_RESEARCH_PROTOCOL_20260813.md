# TS-v5 持续演化策略研究协议

日期：2026-08-13（UTC+8）

状态：`FROZEN_GOVERNANCE_ENGINEERING_AUTHORIZED_LIVE_RESEARCH_NOT_AUTHORIZED`

## 1. 总裁决

TS正式定义为长期策略研究族，不再等同于某条固定入场公式。v3的4%规则和v4的1.5%—4.0%固定
百分比区域仍按原证据停止，不改判、不重跑；它们只作为失败记忆进入后续研究。策略族保持
`TS_FAMILY_ACTIVE`，只有用户明确退役才关闭。

本协议授权候选合同、受限提示、本地静态验证、去重和fixture施工；不授权DeepSeek真实调用、行情或
收益读取、参数回测、模型、模拟仓、Web、scheduler或生产变更。

## 2. 研究对象与不变产品目标

TS继续研究“强市场—强板块—强个股—右侧波段”：月线和周线决定方向与结构，日线寻找5—15个交易
日级别的进入/退出机会；允许较长空仓，只持有少量高置信候选。以下产品约束不是发现期可随意优化的
参数：A股多头、下一合法交易时点执行、T+1、最多两批、禁止下跌补仓、单票不超过10%、最多7只、
总名义仓位不超过70%、真实费用/停牌/涨跌停/容量、`.BJ=0`。

市场/板块/趋势/流动性、入场、退出与风险的精确公式可以研究，但每个候选必须写明相对父版本改变了
什么、为什么可能有效、如何证伪以及需要哪些当前未具备的数据。

## 3. 首轮六个机制家族

首轮只允许下列六个具有不同研究含义的入场机制，不扩成无边界自由代码：

1. `VOLATILITY_ADAPTIVE_PULLBACK`：回调深度随ATR或历史波动调整；
2. `WEEKLY_STRUCTURE_QUANTILE`：使用已完成周摆动区间中的结构分位，而非固定百分比；
3. `BREAKOUT_RETEST`：先突破事前周级阻力，再回踩突破位并恢复；
4. `MOVING_AVERAGE_RESUMPTION`：右侧趋势中回到中期均线附近并重新转强；
5. `CONTRACTION_EXPANSION`：周级振幅/成交收缩后，由日线价格与成交恢复确认；
6. `RELATIVE_STRENGTH_PULLBACK`：板块和个股相对强度仍高时的有限回撤与恢复。

每个机制先做逻辑候选，再在本地对少量参数槽进行优化。禁止让LLM直接给出“最佳收益参数”，也禁止
一次候选混合两个主要入场机制后无法归因。

## 4. 双速研究生命周期

### 4.1 探索沙箱

探索可以使用固定发现期的事件密度、拒绝原因、扣费效果和风险摘要迭代候选；它不宣称样本外。所有
候选和评价都进入追加式尝试记录，失败、重复、解析错误和零事件同样计数。每一代最多保留少量机制
多样且满足复杂度/可成交门的候选，不能只保留历史收益最高者。

探索评价至少同时考虑：事件密度及年度分布、扣费绝对与基准相对结果、回撤/尾部损失、换手、容量、
持仓与行业集中、参数邻域稳定、不同市场状态和与已有候选的行为相似度。没有单一综合分覆盖坏消息。

### 4.2 正式验证

进入验证前另立release，固定候选代码、参数或窄参数范围、全部历史尝试数、发现期选择过程、验证期、
锁定测试、费用与停止门。验证失败不把同一封存期重复用于替补候选；新的逻辑版本回到探索并登记新
尝试。历史通过只得到模拟仓资格，最终只认自然前瞻。

## 5. LLM与本地程序分工

DeepSeek可承担：公开知识归纳、机制候选生成、失败摘要诊断、父候选定向改版、假设—规则—代码语义
复核和反方审查。本地程序承担：合法字段/算子、状态机、PIT、事件生成、参数搜索、回测、成本、统计
校正、去重、选择、审计和所有权威裁决。

允许发送给LLM的只有：本协议、候选Schema、公开知识摘要、可用字段/算子、匿名聚合失败反馈、父候选
及其非封存发现期摘要。禁止发送原始行情、证券清单/代码、持仓/订单、封存验证/测试、自然前瞻、生产
信号、绝对本地路径或任何凭据。

首次建议批次为六个机制各“一次独立候选 + 一次反方改版”，恰好12个完成响应、串行、硬费用上限
0.50美元；这只是待批准的执行提案。调用前必须生成内容哈希、成本上界和精确scope并再次取得用户
授权，未用预算不结转，不递补失败响应。

## 6. 当前施工与停止点

`READY_FOR_BOUNDED_LLM_RESEARCH_APPROVAL`，不能因为本协议已冻结而自动调用DeepSeek或读取任何真实
策略效果。
