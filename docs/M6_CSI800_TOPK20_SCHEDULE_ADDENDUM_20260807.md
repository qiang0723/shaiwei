## 补正口径

`scheduled_names`固定为：

`TopK → W1…W6 → 分数臂 → 调仓日 → 当日计划证券列表`

调仓日严格来自预测交易日序列，从交易步0开始、每10个交易日一次；同一窗口内 Top20/Top30 和三臂
日期键必须完全一致。每个截面证券数必须等于 TopK、不得重复、不得包含`.BJ`。

对每个替代臂，在每个调仓日计算：

`|替代Top20 ∩ 清洗控制Top20| / 20`

最终诊断值是 W1—W6 全部调仓日的等权算术平均，不按窗口先平均，也不加入压力期。旧的单列表 schema
必须失败关闭；合成 fixture 必须覆盖每窗多个调仓日，主指标和独立 auditor 必须各自实现并得到同值。
