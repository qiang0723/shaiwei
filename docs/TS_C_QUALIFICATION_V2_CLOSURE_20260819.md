状态：`CLOSED_PERMISSION_ON_YEARS_COLLAPSED`；策略有效性 `NOT_EVALUATED`；生产授权 `none`

## 事实

v2 唯一画像在"许可开启年"计算后失败关闭：冻结的"该年 ≥50% 交易日许可开启"规则只产生 2 个
许可开启年（2020、2025），低于冻结下限 4。指数月级双许可的逐年开启占比如下（绑定指数数据
机械计算，零事件收益信息）：

| 年 | 开启交易日占比 |
|---|---:|
| 2019 | 42.6% |
| 2020 | 83.1% |
| 2021 | 41.6% |
| 2022 | 0.0% |
| 2023 | 25.6% |
| 2024 | 41.3% |
| 2025 | 66.7% |

结论：v3 的月级双许可使策略在多数年份多数时间空仓——这是设计行为。任何要求逐年密度的资格
门都与该设计结构性不兼容（v1 的逐日历年门、v2 的许可开启年门均因此失败）。
