## 1. 模块

| 模块 | 职责 |
|---|---|
| `contract` | 钉住协议与文档 sha；权限、门（20/2）、锁存、三条重置规则、Web 不改、报告须放行、锁存前禁出净值，任一不符即失败关闭 |
| `segment` | 纯函数：v1 九条日谓词判 live-dual（不过的给出原因）；机械区段（缺口关闭区段，代码快照变化开新区段）；首个达门区段锁存；进度只出计数 |
| `evidence` | 只读加载 |
| `report` | 锁存区段的描述报告（v1 §6 公式）；write-once |
| `cli` | `progress` 与 `report`；完整性失败映射为 `BLOCKED_EVIDENCE` |

`evidence` 的加载内容：
- **SSE 日历**：ingest 账本每参数键最新 trade_cal 批次，逐文件核哈希；评估区间每个日历日都须覆盖，批次之间不得冲突。
- **两账户 PASS 行**：沿用 `paper.query`，逐产物核哈希并校验文档；全量追加式日志须独立重放 PASS。
- **影子信号**：用 `shadow.manifest.verify_signal_manifest` 核对内容哈希，`rebalance_due` 须与账本一致。

## 2. 实现中的口径选择

1. **复用与重写**：架构宪法禁止非 Web 模块导入 `shaiwei.web`，D3 又定 Web 不改，所以 v1 Web 评估器的日谓词与会计门（约 30 行）在本包内按原样重写，不搬动 Web 代码。账户产物、重放与信号核验直接复用 `paper.query` 与 `shadow.manifest`。
2. **缺口与阻断的分界**：
   - **缺口（重置区段）**：某日任一冻结谓词不成立，包括缺行、重复行、受控追赶、非 FORWARD、operator、策略身份、配对身份、会计/新鲜度/北交所。缺口原因逐日披露。
   - **`BLOCKED_EVIDENCE`（证据本身不可信）**：日历未覆盖或冲突、产物或信号哈希不符、日志重放失败、开始时间早于执行日、live-dual 日找不到已核验信号、非开市日出现账户行。
3. **执行警告**：锁存窗口（区段首日至锁存日）内，若有 live-dual 日的影子信号 `on_time=false`，终态为 `OBSERVED_WITH_EXECUTION_WARN`。窗口外的迟到只在日常进度中可见，不改终态。
4. **锁存窗口固定**：描述报告只覆盖区段首日到锁存日，此后区段继续延长也不追加。锚点是两账户在区段首日前最后一个都恰有一行 PASS 的执行日，其证据层（同日或受控追赶）写入报告。
5. **最大回撤**：按冻结公式只在窗口序列上取运行高点，不把锚点 1.0 并入。
6. **评估日**：默认取两账户最新 PASS 执行日中较早的那个；也可显式传 `AS_OF`。
7. **进度输出**：只含日期、计数、原因、代码快照前缀与锁存状态，并显式带 `contains_nav_or_return=false`。
