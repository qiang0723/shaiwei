## 1. 冻结文字给出的边界

G1 原文第④项“入库后组合**净 ICIR/净超额**有增量”，以及“**DSR≥0.95 且** Newey-West(10) t≥3.0”。`g1-v1` 把④解释为两项都要、
点比较即可，把 DSR 作用在候选组合的日净超额上。原文没有规定“增量”用点比较还是显著性检验，也没有规定 DSR 作用在哪条序列上——
g1-v2 只能在这两处**重新解释**；阈值数字（0.95、3.0、10 阶、N 按家族全部尝试计）一律不动。是否允许在已见结果之后重新解释，由用户裁决。

“不放宽”的可检验定义（本协议采用）：g1-v2 在新种子阴性对照上的误放率不得高于 g1-v1（0 次通过），并新增一类 g1-v1 没有的阴性对照（§3）。

## 2. 不变的部分

PIT/shift、复杂度、经济含义、库相关性（只报告的角色不变）；A 层三门；压力期回撤、换手、成本+100%、滑点加倍；90/10 排名混合作为
“入库后组合”的代理；六窗、发现期、标签、成本参数；N 按同研究家族实验总账全部尝试计；`g1-v1` 代码、配置、账本、29 份旧报告原样保留。

## 3. 重标定（`g1-positive-control-v2`，与 g1-v2 规格一同在实现前冻结）

- 路线与强度阶梯同 v1（R1 0.02/0.04/0.06、R2、R3–R5、N1、N2），**全部换新种子**（与 v1 种子不相交）；
- 新增阴性对照 **N3“基线复制”**：因子 = 基线分数 + 独立噪声。它与基线高度相关、却不含基线之外的信息，专门检验新的增量检验会不会
  把“已在基线里的信息”误当增量；
- 终态规则沿用 v1：R1 在 ≤0.04 某档 5 种子中 ≥4 个主判通过、且 N1/N2/N3 零通过 → `G1_CALIBRATED`，否则同 v1 四态；
- 只有 `G1_CALIBRATED` 才允许另立协议：按 g1-v2 重判历史候选、恢复因子线（如 TP-F-0B）。历史 29 个候选在 g1-v2 冻结前**不看**。
