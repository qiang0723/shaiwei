# LLM 持续因子研究线（待方案评审）

> 状态：2026-07-16 已记录方向与待议问题，未授权施工。当前版本三次前瞻影子闭环完成前，
> 不修改研究代码、生产因子、模型、调度或数据口径。

## 定位

筛微的长期核心不应停留在固定 Alpha158 选股，而应持续提高“发现、验证、组合和淘汰独立
Alpha”的能力。LLM 是主要研究发动机，负责检索、理解、提出假设、生成与变异代码、总结
失败；确定性代码、冻结门禁和真实前瞻结果始终是裁判。LLM 不直接控制生产选股、门槛或交易。

现有 CogAlpha-lite 仍是首轮 40 次固定预算的受控实验，不等同于常设系统。只有在筛微真实
数据上证明相对同预算 GP 有独立增量后，才讨论升级为日常持续研究线。

## 输入范围

LLM 因子研究不得局限于观象，候选输入包括：

- 筛微本地行情、量价、财务、行业、市值、资金流、事件及实验账本；
- 观象的产业链、新闻、事件、研报关注、资金异动及判断—结果语料；
- 学术论文、交易所与指数规则、券商研究、基金信函、专业网页和开源代码；
- 后续经授权并通过 PIT、授权、稳定性和数据质量审查的新结构化数据源；
- 历次成功、失败、重复、泄漏和成本后失效的因子研究经验。

必须区分“知识来源”和“因子数值来源”：论文、网页和文本可以启发假设；进入回测的数值必须
来自可追溯、可得时间明确、可持续重建的时序数据。知识发布时间晚于回测期的研究只能标记为
回溯发现，不得伪称当时可发现；最终仍须依靠真正前瞻影子验证。

## 已调研的公开范式

| 范式 | 主要借鉴 | 当前证据定位 |
|---|---|---|
| Alpha-GPT | 人机交互、研究意图转因子 | 早期论文范式 |
| AlphaAgent | Idea/Factor/Eval 分工、AST 新颖性与复杂度约束 | 论文 + 开源研究原型 |
| RD-Agent-Quant | 假设—开发—回测反馈、Qlib、报告转因子 | 公开工程底座候选，非生产即用 |
| Chain-of-Alpha | 生成链/优化链、成功与失败经验池 | 论文范式 |
| CogAlpha | 代码级推理、变异、重组和失败反馈 | ACL 2026 作者实验；CogAlpha-lite 来源 |
| QuantaAlpha | 轨迹级进化、因子库、独立回测和研究界面 | 新开源研究原型 |
| FactorEngine | 非结构化报告转程序、经验知识库、逻辑与参数分离 | 新论文范式 |
| AlphaQT-Bench | 可执行、因果安全、功能正确、结构合规四层审计 | 代码安全门参考 |

公开证据尚未证明任何方案可以在筛微上开箱即用并长期实盘稳定获利。参考这些项目时只吸收
可验证的组件和测试思想，不继承作者回测结论。

## 方案评审触发节点

满足以下条件后再具体讨论实施方案：

1. 锁竞争修复后当前代码版本三次“信号 → 下一交易日开盘对账”完整通过；
2. 验收后已识别的健壮性欠账完成取证、修复和回归测试；
3. Git、飞书、Docker、日增量和影子运行保持干净稳定；
4. 评审只决定研究线方案，不自动授权其进入生产模型或调度。

该评审门与 R1/R2/R3 的施工顺序分开记录；评审时再决定常设 LLM 研究线的实施优先级，当前
不擅自重排已冻结路线。

## 到节点必须讨论的问题

1. **总体架构**：自建轻量内核，还是复用/适配 RD-Agent、QuantaAlpha、AlphaAgent 的组件；
   禁止把外部框架直接接管生产管线。
2. **因子表示**：先用受限 DSL，还是允许更强的 Python 程序；两者的表达力、安全性和审计成本。
3. **知识雷达**：来源白名单、检索频率、版权/授权、正文留存、发布日期、内容哈希和提示注入隔离。
4. **数据注册**：字段语义、PIT `available_at`、覆盖历史、修订规则、来源版本和不可覆盖原始快照。
5. **观象桥接**：是否修改观象“平台完全独立”决策；若批准，只允许单向、只读、版本化、延迟
   快照进入筛微研究区，不共享数据库、不传最终买卖结论、不形成运行依赖。
6. **代码安全**：AST 白名单、禁文件/网络/环境变量/动态执行、资源限额、向量化、功能金样测试，
   以及 AlphaQT-Bench 式动态截断因果测试。
7. **实验纪律**：发现期与 W1-W6 隔离、全部失败计 N、同预算 GP 对照、方向冻结、去重、成本和
   滑点压力、G1 与真实影子准入。
8. **研究节奏**：日常知识更新与假设队列、周度固定预算实验、低频准入和因子衰减/退役机制；
   不允许每天根据回测结果修改生产策略。
9. **模型与成本**：DeepSeek 具体模型、调用上限、缓存、重试、可复现记录和预算熔断。
10. **结果定义**：首轮 40 次 CogAlpha-lite 相对 GP 的继续/暂停条件，以及何时有资格升级为常设
    `LLM Factor Research Loop`。

## 首轮不变的最小验证

- DeepSeek 只做研究生成与变异，不做 G1 裁判；
- 40 次固定总预算，失败、语法错误和沙箱拒绝全部计入 N；
- 与 GP 使用同一数据、发现期、成本、股票池和评价预算；
- 一次只引入一个可归因变量，首轮不同时叠加观象和新资金流；
- 候选必须通过 PIT/shift、复杂度、相关性、W1-W6、压力期、DSR、HAC、成本及组合增量门；
- 未通过只形成可复现 REJECT 和失败经验，不修改门槛追求通过。
