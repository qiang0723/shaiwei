## 3. 程序

1. **复现门**：按各家族 v1 口径重算，复现对照物（逐键最大绝对差 ≤1e-6，键集合一致）；不过的**整个家族**记 `NOT_REEVALUATED`，
   正式执行中不得修补重试。
2. 复现通过后：对同一原始因子用 g1-v2 的 PIT 中性化与逐日配对证据，按 g1-v2 全部 15 门判定；方向规则同 v1（发现期 RankIC 符号冻结）；
   各家族原有的截尾/标准化/基线正交化属于 v1 评估口径，不带入 g1-v2。
3. **家族 N 与多重检验家族**按 v1 证据声明：GP、P1、F1 各自本家族；F2 = F1+F2。按 `family_order`（GP→P1→F1→F2）逐家族先全部记账再判定，
   每个定义追加一行实验记录：判定时 N 为 GP 170、P1 24、F1 12、F2 23（F1 12 + F2 11）；试验方差取所涉家族本次写入的 `selection_increment_ir`。
4. 记账：`ledger/factor_admissions_v2.csv`（经 `shaiwei.ledger.append_*` 唯一入口），报告写 `logs/g1-v2/`；v1 账本与 `logs/g1/` 一律拒写。
5. 每个定义只评一次；不改定义、参数、方向或数据快照；不重新挑选。
