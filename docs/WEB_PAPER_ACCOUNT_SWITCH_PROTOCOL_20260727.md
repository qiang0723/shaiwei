# Web 模拟组合双账户切换协议

> 冻结日期：2026-07-27（Asia/Shanghai）
>
> 协议：`p3-web-paper-accounts-v1`
>
> 状态：`FROZEN_BEFORE_IMPLEMENTATION`

## 1. 目标与边界

本目标只把已经通过独立重放的 `model_top20` 接入现有本机只读 Web 模拟组合页。`model_baseline`
继续作为默认主账户；Top20 是同一不可变 Top30 信号的排名前20等权投影，只能称为“比较账户”，不得
称为新模型、新策略有效样本或优于主账户的方案。

本目标不修改模型、信号、调仓规则、研究门槛、账本、生产数据、scheduler 镜像或 release，不启用
Top20 自动日更，也不增加交易、重跑、调参、删除或写入能力。

## 2. 接入前数据门

接入前必须同时满足：

1. 两账户各有且只有一个账户身份，策略哈希相互独立，初始资金均为 500,000 RMB；
2. 两账户现有 PASS 账户日日期集合相同，账户日键唯一且严格递增；
3. 每份运行账本与不可变 JSON 的账户、日期、信号、策略和产物 SHA-256 一致；
4. 事件 ID 唯一、事件只属于 PASS run、事件序列可重放、会计恒等式成立；
5. 两账户事件中的 `.BJ` 均为 0；
6. `verify_paper_replay` 对两账户分别返回 PASS。

任何一项失败，页面不得通过忽略坏行、退回最新文件或前端扫描账本绕过。

## 3. 观察类型与比较边界

冻结时真实证据为：

- Top30：6 个账户日，其中 BACKFILL 4、FORWARD 2；
- Top20：6 个账户日，其中 BACKFILL 6、FORWARD 0；
- 两账户日期均为 2026-07-17、20、21、22、23、24。

因此本目标只允许“切换账户后查看该账户自身的持仓、现金、会计、账户日和重放证据”，禁止把两个账户
画在同一收益比较图中，禁止输出胜负、收益改善、风险改善或策略有效性结论。Top20 主视图必须明确显示：
当前仅有工程回放、自然 FORWARD 为0、生产自动日更未启用。

未来是否允许同区间比较，必须在足够且日期匹配的自然 FORWARD 形成后另立协议并先冻结最小样本门槛；
不得在看完结果后补定门槛。

## 4. 查询契约

现有四个只读端点增加严格枚举参数 `account_id`：

- `model_baseline`：主账户 · Top30，默认值；
- `model_top20`：比较账户 · Top20。

适用端点为 `/api/v1/paper/portfolio`、`paper/nav`、`paper/forward` 和 `paper/replay`。未知账户必须
返回 HTTP 422；不得接受任意路径、通配符或用户提供的文件名。四个响应必须属于同一账户并保持完全
相同的 `schema_version / snapshot_id / as_of`，否则前端 fail closed。

总览和股票池/信号页继续使用主账户口径，不随模拟组合页局部选择器改变。页面选择不得写入 URL 之外的
生产状态，也不得改变后台默认账户。

## 5. 页面结构

模拟组合页页首先显示双账户选择器、账户角色和目标证券数。默认选择“主账户 · Top30”。切换后：

1. 身份条、持仓、账户日、重放和技术证据全部来自所选账户；
2. Top20 显示“比较账户”“目标20只”“仅工程回放”“前瞻0日”“自动日更未启用”；
3. 当前观察少于8个可比账户日时不画趋势，用精确表格展示，不显示年化、Sharpe 或信息比率；
4. BACKFILL 与 FORWARD 继续分层，不把回放日混入前瞻结果；
5. 账户切换时不得暂时把旧账户数字标成新账户，加载/错误状态必须可见；
6. 手机、键盘、400% 缩放和技术证据下钻能力不得因选择器退化。

## 6. 验收门

通过条件：

1. 协议与机器配置先于实现提交并推送；
2. 后端只接受两个冻结账户，默认行为与旧 `model_baseline` 字节口径兼容；
3. Top20 四端点同快照，账户、策略、日期、观察类型和重放状态与不可变证据一致；
4. 前端默认 Top30，能够切换 Top20，且主视图不出现跨观察类型的收益比较；
5. Top20 0 FORWARD 的空态可读、可访问、无误导性图表或风险调整指标；
6. Python、TypeScript、前端单元、真实浏览器、响应式、axe、CSP、脱敏和 `git diff --check` 通过；
7. 只重建隔离的 Web 服务，scheduler 容器、镜像、创建时间和健康状态不变。

任一查询需要读取白名单外文件、需要修改冻结账本，或页面无法避免把回填表现包装成前瞻比较时，本目标
立即停止并保持 Top30 单账户页面。
