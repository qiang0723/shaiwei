# TS-v4A 回调深度参数研究与样本外验证协议

日期：2026-08-12（UTC+8）

状态：`FROZEN_NOT_EXECUTION_AUTHORIZED`

## 1. 为什么继续、又为什么不能直接“调到赚钱”

TS-v3 的停止只证明“上一完整周 VWAP 下 4% 后恢复”的精确规则在 2019—2024 只有 8 个可用于效果的
合法事件，无法可靠评价收益；它没有证明趋势内回调机制无效。用户决定继续 TS，并允许研究更合适的
参数，以形成扣除成本后相对更好的收益。

本协议把继续研究转成一个可证伪问题：只改变回调深度，其他市场、板块、月周结构、恢复确认、止损、
止盈、持有期、仓位、容量和真实成交规则全部不变。这样以后即使收益改善，也能归因于“回调深度”，
而不是多项规则同时改动。

目标不是找历史收益最高的单点，而是找相邻参数都成立的稳定区域，再用后续时间段检验。回测过拟合
研究指出，反复尝试并挑选最优历史路径会显著提高样本外失败概率；因此本协议机械计入全部四臂，使用
封存验证、锁定测试和 DSR，不把失败或稀疏参数从尝试数中删除。

方法校准参考：

- [The Probability of Backtest Overfitting](https://papers.ssrn.com/sol3/Papers.cfm?abstract_id=2326253)
- [The Deflated Sharpe Ratio](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)
- [中证指数股票指数计算规则](https://oss-ch.csindex.com.cn/contract/cms_add/20240726155028-%E3%80%8A%E4%B8%AD%E8%AF%81%E6%8C%87%E6%95%B0%E6%9C%89%E9%99%90%E5%85%AC%E5%8F%B8%E8%82%A1%E7%A5%A8%E6%8C%87%E6%95%B0%E8%AE%A1%E7%AE%97%E8%A7%84%E5%88%99%E3%80%8B.pdf)

外部方法只约束验证设计，不作为筛微策略有效的证据。

## 2. 唯一参数轴与四个尝试

回调线统一为“上一完整周复权 VWAP ×（1−回调深度）”，只运行：

| 尝试 | 回调深度 | 角色 |
|---|---:|---|
| `TS4-D015` | 1.5% | 较浅回调 |
| `TS4-D025` | 2.5% | 中浅回调 |
| `TS4-D035` | 3.5% | 中深回调 |
| `TS4-D040` | 4.0% | v3 冻结对照 |

四个参数在任何收益读取前同时冻结，正好计四次策略尝试。不得追加 2%、3%、4.5% 等参数，也不得把
稀疏、报错或亏损的臂从多重检验 N 中删掉。

保持不变的关键规则包括：触达后收盘高于前一有效日高点且为阳线；初始止损为上一完整周低点下浮
2%；只认紧邻下一官方开盘且开盘不高于周 VWAP、止损距离严格小于15%；最多两批、第一批最多5%、
单票最多10%、最多7只、总仓位70%；止盈为`min(第一批成交+1.5R, 第一批成交×1.20)`，最长持有15个
官方交易日。Alpha158只在合格候选争夺有限仓位时排序，不参与触发。

## 3. 三段时间与诚实边界

- 发现期：2019-01-02—2021-12-31，四臂只在这里比较和选择；
- 验证期：2022-01-04—2023-12-29，只运行发现期机械锁定的一臂；
- 锁定历史测试：2024-01-02—2024-12-31，只有验证通过才打开。

每段末尾删除无法在本段内完成“次日入场 + 最长15日退出”的最后16个信号日，下一段数据不得替上一段
补结果。Alpha158 OOS 真身只覆盖 2019-01-02—2024-12-31，故不使用2016—2018或2025，也禁止用
当前模型回填。

2024 虽然在本次运行前保持 TS 收益未读，但它的市场环境已经被项目多次用于压力讨论，因此只能叫
“锁定历史测试”，不能宣称完全未知样本外。真正未知证据仍只能来自未来自然模拟仓。

## 4. 先做不读收益的密度门

第一步只在发现期计算四个状态机事件，不读取入场后路径或 Alpha158 分数。每臂至少30个合法事件、
20个不同信号日、三个年度每年不少于5个，事件键对冻结 Alpha158 缓存覆盖100%。至少存在一对相邻
参数同时通过，才允许进入效果；否则`STOP_NO_DENSE_PARAMETER_REGION`。

这个门解决“参数仍然太稀疏”，不能告诉我们哪个参数赚钱。真实密度画像仍须在本协议提交推送后另立
一次性 release，当前没有执行授权。

## 5. 发现期如何选，不追尖峰

四臂全部以50万元独立账户、完整两批状态、真实费用和可成交规则运行并各复放一次。单臂必须至少30笔
闭合交易、每年不少于5笔、合并净收益和 H00906 净超额均为正、三年至少两年净超额为正、最大回撤
不超过20%，且双倍成本及买卖各加10bp后净收益不为负。

候选参数还必须与相邻参数形成平台：双方通过全部硬门；较弱一方净超额至少为较强一方的50%；回撤差
不超过5个百分点；交易数之比不低于50%。最终只在平台成员中按“三年净超额中位数最高 → 回撤最低 →
换手最低 → 回调更深”机械选一臂，并要求把全部四次尝试计入后的 DSR 不低于0.95。没有稳定平台或
DSR失败就拒绝，不选孤立的收益尖峰。

## 6. 验证、锁定测试与停止

验证期只运行已经锁定的一臂，不准失败后换第二名：至少15笔闭合交易，合并净收益和 H00906 净超额
严格为正，至少一个年度净超额为正，每个年度净收益不得低于-5%，最大回撤不超过20%，双倍成本和
额外滑点下仍不亏。任一失败即`REJECT_TS_V4_VALIDATION`。

验证通过才打开2024：至少8笔闭合交易、净收益为正、最大回撤不超过20%、双倍成本和额外滑点不亏；
并要求2022—2024合并 H00906 净超额为正，三个年度至少两个净超额为正。通过只得到
`GO_TS_V4_HISTORICAL_NOT_FORWARD`，仍不授权模拟仓、Web或生产；失败为
`REJECT_TS_V4_LOCKED_TEST`，不允许换参数重测。

报告必须同时展示绝对收益、H00906相对收益、回撤及持续时间、胜率、盈亏比、每笔期望、换手、费用、
滑点、容量、持有期、现金比例以及行业/证券/交易盈亏集中度。没有一个单独“综合高分”可以覆盖坏消息。

## 7. 基准、费用与当前授权

主基准仍是可审计的中证800全收益指数 H00906。它与价格指数的差别在于全收益指数考虑现金分红再投资，
所以不得用`000906.SH`价格指数或本地拼接代理替代。当前 H00906 尚未绑定；任何收益运行前须另立
官方或有审计许可的数据恢复并完成谱系门。

费用按历史时点计算：佣金双边3bp且每笔最低5元；过户费在2022-04-29前双边0.2bp、当日起双边
0.1bp；卖方印花税在2023-08-28前10bp、此后5bp；另跑双倍成本与买卖各加10bp场景。停牌、T+1、
涨跌停、跳空和容量不足不得伪造成计划价成交。

本次只冻结协议和可测试合同：收益读取、H00906取值、Alpha158分数、真实密度画像、回测、模拟仓、Web、
生产、外网和密钥均未授权。机器真身为`config/ts_v4_parameter_research_v1.yaml`。
