# M6-3A 中证800 Top20 组合转换协议（历史效果读取前冻结）

- 冻结时间：2026-08-07 09:54:14（UTC+8）
- 协议 ID：`m6-csi800-topk20-portfolio-conversion-v1`
- 机器真身：`config/m6_csi800_topk20_conversion_v1.yaml`
- 当前阶段：`RESULT_BEFORE_TOPK20_PORTFOLIO_PROTOCOL_FREEZE_ONLY`
- 生产授权：`none`

## 1. 本批只回答一个问题

M6-2R 已经确认：Ridge 与 LightGBM/Ridge 固定融合都改善了 RankIC，但固定 Top30、`n_drop=3`、10 日
调仓没有把分数增量转化为更好的扣费组合结果，权威归因为
`PORTFOLIO_CONVERSION_BOTTLENECK_INDICATED`。

M6-3A 不再增加模型、因子或 seed，只冻结一个后续可证伪问题：复用 M6-2 完全相同的三组预测，将
`portfolio.topk` 从 30 改为 20，是否能让既有替代分数相对清洗 LightGBM 控制组的组合增量得到改善。
这里的“Top20”是唯一治疗值，不测试 Top10、Top15、Top25、多个 TopK 或看结果后换宽度。

## 2. 为什么选择 Top20

选择 Top20 不是因为已经看到 M6 的 Top20 历史效果，而是基于三个结果前理由：

1. M6-2 的分数门通过、换手约束也通过，失败集中在固定 Top30 的组合转换，优先检验选择宽度比继续
   增加模型更符合现有证据；
2. Top20 是相对 Top30 的单一、可解释收窄，能检验分数增量是否集中在更靠前的证券；
3. 项目已有独立 `model_top20` 模拟账户协议，说明 20 只目标可被清晰操作化。但该账户使用正式 Top30
   信号、50 万元会计与真实成交约束，不是本次一亿元历史研究的效果输入；其相对业绩没有用于选择参数。

本批不会把模拟账户结果和历史回测混在一起，也不会把 Top20 冒充新模型。

## 4. 可比性先于 Top20 结果

未来组合专用执行器必须先使用同一封存预测复现 Top30。六窗、三个分数臂的规范日报若不能与 M6-2
逐内容一致，必须在任何 Top20 效果裁决前返回 `BLOCKED_PRE_EFFECT`。这一步用于证明新执行器没有
偷改成交、成本、日期或持仓语义，不得用数值容差掩盖身份漂移。

Top30 复现通过后，才可生成 Top20 组合。模拟账户产物、前瞻账户日和 Web 查询均不得作为历史输入；
`.BJ`、预测成员日变化、非有限值、覆盖不足或 effect 树漂移均失败关闭。

## 5. 正式检验与门槛

保留两个且仅两个正式假设，分别对应既有 Ridge 和固定融合分数。主要日序列为：

```text
(替代Top20净主动收益 - 控制Top20净主动收益)
- (替代Top30净主动收益 - 控制Top30净主动收益)
```

W1—W6 按时间拼接，在1.0x成本下执行单边 Newey-West(10)，并对恰好两个假设做 Holm 0.05 校正。
这项差分中的差分检验直接回答：收窄 TopK 是否改善替代分数相对控制分数的组合转换，而不是只比较
两个互不相干的净值。

`TOPK20_CONVERSION_SUPPORTED` 要求至少一个替代臂同时满足：

- 主要 Holm 检验通过，pooled 差分中的差分严格为正，且至少4/6窗口为正；
- 在 Top20 内相对清洗控制组的 pooled 基础净超额增量严格为正，至少4/6窗口为正；
- 1.5x、2.0x成本下 pooled 增量均不为负；
- 换手不超过 Top20 清洗控制组的110%；
- 六个 test 窗和合法压力期的策略净值最大回撤不超过20%。

M6-2 已审计的 RankIC 通过事实只作为固定上游条件，不重新形成模型假设或新门槛。报告必须拆开
Top20/Top30净主动收益、直接增量、差分中的差分、毛收益、成本、换手、回撤和计划 Top20 名称重合，
禁止只给一个综合分。

## 6. 尝试计数与终态

本批新增模型尝试为0；两个既有替代分数对应两个组合转换假设。首次获批读取 Top20 效果时一次性消费
恰好2个组合尝试，执行器或审计在读效果后失败也不得递补。

- `TOPK20_CONVERSION_SUPPORTED`：至少一个臂同时通过主要交互门和 Top20 直接组合门；只允许主控评审
  下一独立阶段，不代表策略有效或生产准入。
- `TOPK20_CONVERSION_NOT_SUPPORTED`：两臂均未通过两门；关闭 M6 系列并进入 A1-0 只读代码盘点。
- `MIXED_NOT_CONCLUSIVE`：只过一门或两臂冲突；停止，不追加其他 TopK、`n_drop`、调仓、权重或模型。
- `BLOCKED`：输入身份、Top30复现、覆盖、确定性、执行或独立审计不完整。

所有终态的 `strategy_effective` 都保持 `NOT_EVALUATED_FOR_PRODUCTION`，生产授权均为 `none`。
