# Web 1.1 移动实验目录可读性补正验收（2026-07-26）

## 1. 结论与边界

390px 实页中实验目录的机器枚举碎片化折行已消除，结论为 `GO_LOCAL_READ_ONLY_REVIEW`。本补正只修改
Web 前端、前端测试和验收截图；未修改后台 API、`src/`、config、模型、门禁、账本、生产数据、compose
边界或 scheduler。

## 2. 设计裁决

1. 699px 以下不再渲染桌面宽表，改为高度受控的三列目录：实验 ID、结论、权威状态。
2. 结论和权威状态只显示中文业务语义；原始英文机器枚举保留在 `title`、`aria-label` 和详情页用于审计。
3. “发现层拒绝”“方法已失效”“权威停止”“仅发现层”等负面或受限结论保留原语义和警示色，不降级为
   中性状态。
4. 每条目录行不超过 72px；不恢复移动长卡片墙，也不隐藏精确筛选、分页或证据下钻。

## 3. 验收结果

- 前端生产构建与 TypeScript：PASS。
- 前端单元：22 PASS。
- 390/320px 实验目录专项：2 PASS；断言移动目录可见、桌面目录隐藏、中文坏消息可见、机器枚举正文为 0、
  单行高度不超过 72px。
- 五视口 fixture Playwright：64 PASS / 11 条按项目条件跳过。
- 真实部署桌面/移动 Playwright：10 PASS；覆盖 axe serious/critical=0、严格 CSP、同源零外联和页面回流。
- 全仓：339 PASS；Ruff、`git diff --check` 通过。
- 真实 390px 全页高度：3,617px → 2,740px，减少 877px（24.2%）；页面宽度保持 390px，无文档级横向
  溢出。

- 更新截图：`artifacts/web-1.1/after/experiments-real-mobile.png`（390 × 2,740）。
- 浏览器仍只通过 `127.0.0.1:8080` 访问；`web-query` 无宿主端口。

  `fd8e96152b53`、同一镜像和创建时间，状态 healthy。

写入、重跑、调参或交易能力。
