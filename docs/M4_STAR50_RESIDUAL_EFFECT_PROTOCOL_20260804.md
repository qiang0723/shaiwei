## PIT、中性化与标签

- 信号时钟为当日收盘；成员、行业和总市值都必须是信号日PIT状态；`.BJ`出现即fail closed。
- 标签固定为下一官方交易日开盘到再后10个交易日开盘的收益，即与既有
  `Ref($open,-11)/Ref($open,-1)-1`同一经济时钟；两个复权开盘价缺一即不可估计。
- 日截面先按1%/99% winsorize再标准化。发现期和压力诊断对行业与log总市值残差化；封存样本外还要
  对同日冻结Alpha158分数残差化，确保检验的是基线未解释的增量信息。
- Alpha158不重训，逐文件绑定P2-2C纠错后first-pass预测真身。旧P2-2的失效预测不得使用。
