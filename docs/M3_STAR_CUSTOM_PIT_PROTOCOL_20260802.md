# M3-0 科创板规则型 PIT 研究池数据与规则协议

> 日期：2026-08-02（Asia/Shanghai）
>
> 协议：`m3-star-custom-pit-data-rule-gate-v1`
>
> 状态：`FROZEN_BEFORE_MEMBERSHIP_CONSTRUCTION`
>
> 机器真身：`config/m3_star_custom_pit_v1.yaml`

## 1. 目标与边界

本目标只回答：现有不可变本地历史数据能否按当时可知规则，确定性构造科创板全市场、中盘和小盘
三个自建研究池。它们统一标记 `CUSTOM_RULE_BASED`，不是科创100、科创200或任何官方“科创300”
指数，也不复制官方固定样本数。

协议冻结与推送前不得生成成员数量、因子、IC、收益、回撤、排名或信号。全程不调用 DeepSeek，
不运行 qlib、模型、回测或 G1，不修改生产 scheduler、中证800、科创50/100/200既有证据或 Web。
数据门 GO 只允许后续另立结果前因子协议；策略有效性仍为 `NOT_EVALUATED`，生产授权为 `none`。

## 2. 股票身份与 PIT 存续

- 主源仅为 ingest ledger 登记并逐文件验哈希的 Tushare 原始批次；截止日固定为 2026-07-31。
- 科创板证券必须同时满足：`market=科创板`、`exchange=SSE`、代码匹配
  `^(688|689)[0-9]{3}\.SH$`。三者不一致即失败，不能用代码前缀静默补漏。
- 存续区间固定为 `[list_date, delist_date)`；退市生效日及以后直接移出，`.BJ` 永久禁止。
- 股票须上市满 12 个日历月才可参加形成日筛选。不得用未来上市、退市或当前成员信息回填历史。
- ST/风险警示来自 `namechange` 的时点区间。有效起点取 `start_date` 与非空 `ann_date` 较晚者，
  结束日含当日；同一有效起点有任一 ST 名称即保守判 ST。无任何名称变更历史本身不等于 ST。

## 3. 月度形成、流动性与规模

每月最后一个上交所交易日收盘形成，下一上交所交易日生效。形成计算只可读取形成日及以前数据：

1. 流动性取截至形成日最近 60 个交易日的原始日成交额中位数；至少 45 个正数有效日，且中位数
   不低于人民币 2,000 万元。Tushare `amount` 按千元乘 1,000 转成人民币元。
2. 规模取截至形成日最近 20 个交易日的 `total_mv` 中位数；至少 15 个正数有效日。Tushare
   `total_mv` 按万元乘 10,000 转成人民币元。规模只用于排序，不设结果后绝对市值线。
3. 通过上市时长、存续、ST、流动性和规模门的证券组成全市场池。按规模中位数降序、代码升序打破
   并列，再用确定性的三等分切成大/中/小三段；余数依次分给大、中、小段。大段不单独登记，
   中段和小段分别成为中盘池、小盘池，全市场池包含三段。

形成后如证券进入 ST 或到达退市生效日，逐日硬退出；若它原本属于该月形成集合且随后摘帽，可在
下一形成日前按原分段恢复。不得因月中退出重新排序或把别的证券递补进来。

## 4. 数据质量与可用起点

必需源为 `trade_cal / stock_basic / namechange / daily / daily_basic`。逐文件哈希、交易日历、证券身份、
日行情和日频市值主键必须通过；重复键、未来日期、身份不一致或 `.BJ` 任一非零即失败。所有正数
行情 bar 必须有同日正数 `daily_basic.total_mv`，覆盖率固定为 100%，避免以缺失市值选择性删票。

结构可用门在看成员数量前固定为：全市场至少 60 只、中盘至少 20 只、小盘至少 20 只，并至少存在
36 个连续合格月度形成。可用起点机械定义为首个合格形成的下一交易日；此前如实标 `NOT_READY`，
不得回填。起点以后任何月度形成再跌破门槛，整个数据门失败。

## 5. 产物与裁决

忽略目录内生成月度形成成员、逐日成员和质量报告；Git 只提交配置、代码、fixture、脱敏 manifest、
协议和验收文档。成员主键分别为 `(formation_date, universe_id, ts_code)` 和
`(trade_date, universe_id, ts_code)`；中盘/小盘必须互斥且均为全市场子集。相同输入复跑须复用完全
相同的 Parquet 和报告哈希，不能覆盖不一致缓存。

`source_gate_pass / pit_gate_pass / readiness_gate_pass / output_gate_pass / idempotency_pass` 全部为真，
才裁定 `GO_CUSTOM_PIT_DATA_RULE_GATE_ONLY`；否则裁定 `NO_GO_CUSTOM_PIT_DATA_RULE_GATE` 并停止。无论
GO/NO-GO，都不得在本目标中放宽门槛、计算因子或进入模型。
