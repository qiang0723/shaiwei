# TS-1A v3结果盲量化与数据门协议

日期：2026-08-12（UTC+8）

机器真身：`config/ts_v3_data_gate_v1.yaml`

状态：`FROZEN_BEFORE_REAL_PROFILE_NOT_EXECUTED`

## 1. 唯一问题

本节点只判断现有不可变数据能否把TS v3整理成一个没有主观歧义的候选漏斗。允许读取当时已经形成的
价格、成交、市值、市场/板块、PIT成员和Alpha158分数；禁止读取候选入场后的收益、MAE/MFE、胜率、
组合收益或任何可以用于择优的效果。

输出只能是字段/日期覆盖、分布、逐层数量、空仓期、容量/风险可行性和身份哈希。TS-1A不推荐股票、
不训练、不预测、不回测、不创建模拟仓、不写Web、不修改生产。

## 2. 股票池与两层基准

首版股票池固定为历史PIT中证800，排除`.BJ`、ST和退市整理。它既能继承现有Alpha158 OOS分数，又
避免在TS首次验证时同时扩张股票池；通过后再另立全A扩展版本。

“不能只看中证800”的要求按两层实现：

1. 官方大类指数只负责市场安全：主板用中证800，创业板用`399006.SZ`，科创板用`000688.SH`；
2. 热点选择使用当时PIT申万一级行业成员，在PIT中证800成员内以复权收盘日收益构造等权行业篮子，
   明确标为“TS派生行业篮子”，不得冒充官方行业指数。

缺创业板或科创板官方指数历史时返回`NOT_EVALUABLE`，不得用中证800、当前指数或未来历史补齐。

## 3. 热点板块唯一初始定义

行业篮子每天至少5个有效成分。板块必须同时满足：

- 收盘高于20日均线；
- 最近20日和60日收益分别高于所属大类指数同期收益；
- 最新完整周低点不低于上一完整周低点。

全部通过后按20日相对收益降序取最多3个热点板块，同分按行业代码。该规则在真实画像前冻结，不做
权重打分和多阈值择优；若数据或漏斗表明不可构造，只能BLOCKED并另立协议，不能查看效果后修改。

## 4. 已冻结和待画像规则

已冻结硬门：市值200亿元、上一完整周成交额50亿元、三个月支持连续两个月高点提高、三根完整周K
低点不下移、最新周收盘不低于周高低点中位。单日30亿元只作放量标记。

仍只能画像、不能先定阈值：

- 最新月低点相对前月低点的变化；
- 连续两周的周振幅与日频实现波动分布；
- 回调到前周VWAP或前周中位价的事件数量；
- 恢复日到下一开盘的跳空分布；
- 买入价到`上一完整周低点×98%`的止损距离；
- Alpha158在事件日的覆盖和成熟时间。

TS-1B只能从这次不可变画像中形成一个业务可解释的口径，不得使用入场后收益选择阈值。

## 5. 输入与失败关闭

输入只认项目内采集账本、不可变原始批次、已登记PIT/Alpha158真身和逐文件哈希。缺源、主键重复、
`.BJ`、未来行业回填、无法解释缺bar、指数历史空洞或Alpha158覆盖不足均返回对应`BLOCKED_*`。

当前盘点已经确认：个股日线、复权、市值、成交额和PIT申万行业存在；创业板官方指数历史尚未在已见
生产基准中确认，行业热点也尚无冻结派生篮子。真实读取后若仍缺，TS-1A应如实BLOCKED并给出精确补数
计划，不得退回统一中证800许可。

## 6. 验收与停止线

工程实现须位于独立`shaiwei.research.trend_swing`窄模块，领域计算不导入Web、Docker或生产编排，
每个新文件常态不超过400行。必须有停牌、跨周/月、不完整周月、行业变更、板块成分不足、`.BJ`、
重复键、缺指数和未来分数的对抗测试。

真实画像最多执行一次；报告与输入manifest write-once，并由独立重算核对。完成后只允许更新状态并
给出`GO_TS_V3_FREEZE`或一个/多个`BLOCKED_*`，不得继续TS-1B、效果、模拟仓或Web施工。
