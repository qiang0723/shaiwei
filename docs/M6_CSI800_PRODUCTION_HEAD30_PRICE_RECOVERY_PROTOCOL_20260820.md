# M6-4B-R2 生产 Head30 空成交价恢复协议（结果隔离）

## 目标

修复 R1 在真实处理臂首遍暴露的单一执行适配缺陷：成交价接口返回空值时，适配器在进入既有持仓
价格回退前执行了 `float(None)`。R2 只恢复原先已经存在但无法到达的回退路径，不选择新的价格源，
不修改模型、预测、排名、Head30、等权、调仓、成本、窗口或 G0。

## 冻结语义

1. 成交价是有限正数时直接使用；`None`、非数值、非有限或非正数统一表示“无成交价”。
2. 估值已有持仓时，无成交价进入原有 `current.get_stock_price` 回退；回退值必须是有限正数，否则以
   `FullTargetStrategyError` 失败关闭。
3. 新目标的买入价缺失继续沿用既有行为：目标数量为 0，不生成买单。
4. 禁止新增前收盘、未来收盘、复权收盘或人工价格；禁止删除证券、交易日、信号或改变目标排名。

## 结果隔离和尝试计数

- R1 的 authorization、started、failure 三份产物和哈希永久保留；R1 已消费 1 次尝试且不得重跑。
- R2 工程期不得读取 Qlib、封存预测、控制报告或收益；只允许纯合成/对抗 fixture。
- R2 使用新目录 `effect-r2` / `effect-r2-audit`，不得覆盖或复用 R1 输出。
- 未来首次获批读取 R2 真实处理效果时再消费 1 次新组合转换尝试；届时本家族累计为 2 次。失败仍
  消费，同一 R2 scope 不得重跑。

## 工程与发布边界

实现应把价格规范化放在 `full_target` 领域适配器内，并直接测试空值、NaN、无穷、非正数、合法价格
及二级回退失败；release validator 必须绑定 R1 失败证据、新输出根和新批准动作。隔离 Docker 不挂载
`.env`、生产账本、Docker socket 或整仓，运行时断网、只读根、非 root。

工程、不可变镜像、daemon 级零效果 fixture 和精确 scope 完成并推送后立即停止。真实 runner、
replay 和 auditor 必须由用户绑定新 scope SHA-256 再次明确批准；生产授权始终为 `none`。
