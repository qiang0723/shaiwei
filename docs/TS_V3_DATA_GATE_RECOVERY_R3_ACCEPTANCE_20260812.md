## 4. 结果盲候选画像

冻结规则形成 832 个匿名候选事件，分布在 331 个交易日，832 个均存在下一交易日合法开盘；最长连续
空候选期为 136 个交易日。该统计用于判断规则可运行和空仓特征，不是收益或选股结论。

需要在下一结果前协议处理的主要风险是止损跨度：结构止损距离中位数约 17.99%，P95 约 33.95%，
832 个事件中 535 个不低于 15%（约 64.3%）。因此“上周低点下浮 2%”不能直接等同于固定 2% 风险；
下一阶段必须同时冻结按止损距离缩放仓位、单票风险、组合风险和过宽止损拒绝规则，不能看完收益后调整。
