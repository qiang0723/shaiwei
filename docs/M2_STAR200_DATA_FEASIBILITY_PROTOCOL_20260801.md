## 1. 目标与边界

科创200是M1-0注册的官方小市值科技股票池，但当前只有身份登记，没有可审计的历史成员PIT数据门。
M2-0只回答“能否从当时已公开的一手资料重建科创200官方成员谱系，并用二级数据核验”，不计算因子、
IC、收益或回撤，不构建qlib，不训练模型，不生成排名、信号或模拟账户，也不修改现有生产系统。

研究顺序固定为：

`官方身份 → 首批名单 → 规则版本 → 调整事件 → 逐日PIT成员 → 二级集合对账 → 数据门裁决`

任何后续因子或策略协议都必须晚于本数据门GO；数据GO也不等于因子、模型或策略有效。

## 2. 冻结身份与时间边界

- 指数：上证科创板200指数，`000699.SH`；provider代码`000699`；qlib基准代码`SH000699`。
- 官方发布公告日：2024-07-21；正式发布日：2024-08-20。
- 编制方案基日：2022-12-30。基日不是当时已公开的成员事实，禁止把研究成员历史前移至正式发布前。
- 数据截止日：2026-08-01；最后完整交易日：2026-07-31。
- 最早可能的研究可用日固定为2024-08-20，且只有首批200只名单和之后的全部调整事件闭合时才成立。
- `.BJ`在原始集合、事件、逐日成员及二级对账中均必须为0。

## 3. 官方一手证据范围

成员真身只认上交所或中证指数官方材料：

1. 2024-07-21发布公告、V1.0编制方案和首批样本附件；
2. 从发布公告日至截止日的全部定期与临时调整公告及可证明发布时点的成员附件；
3. 2025-02-26修订公告，以及2025-03-17生效的V1.1编制方案；
4. 官方归档必须扫描到发布日前，范围内候选公告必须逐项分类，不能只搜索命中页面。

V1.0新股纳入门槛为上市超过6个月；V1.1从2025-03-17起改为上市超过12个月，并采用新老样本划断。
当前规则不得倒灌历史。每条成员变化必须绑定公告日、生效日、调出、调入、官方URL、原文SHA-256、
抓取时间和解析器版本。公告晚于生效、缺少成对替换、同批重复、模糊日期或事件后成员数不是200时
全部fail closed。

官方公告若表述为某日收市后生效，成员集从下一官方交易日起应用；若明确在某交易日开盘前生效，
则从该日应用。禁止从Tushare月末快照反推公告日或生效日。

## 4. Tushare二级证据角色

Tushare只承担以下二级角色：

- `index_daily`：核验2024-08-20至2026-07-31指数日线对SSE官方开市日的完整性；
- `index_weight`：按2024-08至2026-07共24个完整月份，核对官方逐日谱系在每个月度快照日的成员集合。

请求按年度/月度显式分区，串行执行，每项写盘前必须即时双查且内容完全一致。`index_weight`权重数值
只作诊断，不进入未来等权研究；接口的`trade_date`不得冒充官方生效日。该接口没有发布时间、版本号
和修订原因，因此不能独立成为历史PIT真身。

## 5. 数据质量硬门

- 首批名单恰好200只、唯一成员200只、`.BJ=0`；
- 规则V1.0、修订公告和V1.1的内容与生效边界全部闭合；
- 官方归档越过首发边界，范围内定期/临时调整公告全部分类并可解析；
- 每个调整区间都有官方成员对，公告/生效/来源哈希齐全，事件重复、成员重复和未来回填均为0；
- 2024-08-20至2026-07-31每个官方开市日恰好200只成员；
- 24个月的Tushare快照各恰好一个交易日、200行和200个唯一成员，与官方当日集合差异为0；
- 指数日线对官方开市日覆盖100%，重复、非日历、OHLC/非负及涨跌幅异常均为0；
- 原始和派生产物全部绑定SHA-256；相同入口复跑必须零新增请求、零改写且哈希不变；
- Git只跟踪脱敏manifest、配置、代码、测试和文档，不跟踪原始/派生业务行、日志或秘密。

## 6. 机器裁决

全部硬门通过只能裁定：

`GO_OFFICIAL_LINEAGE_AND_SOURCE_DATA_ONLY`

任一必需门失败则裁定：

`NO_GO_M2_STAR200_DATA_GATE`

NO-GO时保留已经取得的不可变证据并停止，不能用当前成分、ETF PCF、基金持仓、Tushare月度集合或
人工表格补造官方历史。若官方谱系不闭合，策略状态保持`NOT_EVALUATED`，不能表述为科创200无效。

## 7. 工程与生产隔离

- 新工具按采集、官方发现/解析、审计与合同分责，生产文件以400行为常态，禁止复制成新的单文件巨石；
- 采集和解析只写项目`data/research/star200/m2-star200-v1/`忽略目录；正式服务仍只用Docker；
- 国内源走项目既有直连/`NO_PROXY`路径，不修改Mac系统代理或Clash；需要用户网络操作时必须先报告；
- 不读取或输出`.env`秘密；只有Tushare客户端在受控调用点读取token；
- 不修改`src/config`生产路径、模型、门禁、信号、账本、Web契约、Compose或scheduler镜像；
- 不构建或重启生产scheduler，不触碰2026-08-03 Top20一次性发布守护。
