## 3. 六个候选和固定方向

| 候选 | 固定公式 | 方向 | 经济含义 |
|---|---|---:|---|
| 资产增长 | `total_assets_t / total_assets_t_minus_1 - 1` | -1 | 约束过快扩张、投资效率和融资尾部风险 |
| 收入增长 | `total_revenue_t / total_revenue_t_minus_1 - 1` | +1 | 需求、份额或业务规模扩张 |
| 营业利润变化 | `(operate_profit_t - operate_profit_t_minus_1) / average_total_assets` | +1 | 主营经营成果的增量效率 |
| 归母净利润变化 | `(n_income_attr_p_t - n_income_attr_p_t_minus_1) / average_total_assets` | +1 | 股东盈利能力的年度改善 |
| 经营现金流变化 | `(n_cashflow_act_t - n_cashflow_act_t_minus_1) / average_total_assets` | +1 | 盈利兑现和内部造血改善 |
| 货币资金变化 | `(money_cap_t - money_cap_t_minus_1) / average_total_assets` | +1 | 流动性缓冲和逆周期选择权改善 |

方向不是超参。发现期平均 RankIC 与登记方向相乘必须严格大于 0；否则仍计一次正式尝试，在读取其
OOS 组合效果前终止，不得翻向后重赛。合法不可估计记录继续保持为空，禁止填补或用未来报告补齐。

## 4. 可比增量设计

月末 PIT 特征形成后从下一开盘可用，并前向保持到下一形成日；每行必须保留来源形成日且不得使用未来
快照。先对原始候选做日横截面 1%/99% 缩尾，再剔除 PIT 申万一级行业与标准化对数总市值；2019—2024
六个 OOS 窗额外联合剔除冻结 Alpha158 分数。发现期与非 OOS 使用 core，六个 OOS 窗使用 incremental。

组合仍是 `90% Alpha158 日排名 + 10% 固定方向后的基本面动态残差排名`，沿用 Top30、`n_drop=3`、
每10个交易日调仓和次日开盘。标签为信号日 `t` 至 `t+11` 的开盘收益。先固化不含标签/收益的残差
面板，再由效果 runner 只读；残差阶段不得读取标签、IC、收益或持仓。
