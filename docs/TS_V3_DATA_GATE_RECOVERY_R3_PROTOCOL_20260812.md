R2 的实现已通过合成测试，但 release、claim、密钥读取、provider 请求、原始批次提交和真实画像仍
全部为 0。提交前对三条指数执行统一官方日历 anti-join 时发现：中证800在 2016-01-04 至
2026-08-11 的冻结范围内还缺 2026-07-15 一天。旧 TS-1A 报告记录中证800为 2,575 日、官方日历为
2,576 日，却只检查“指数是否存在”，没有把日期集合差设为硬门。

因此 R2 原件永久保留为 `SUPERSEDED_BEFORE_EXECUTION_BY_R3`，不构成一次网络或画像失败，也不消耗
用户授权。R3 只新增这一个已经用键级差集确认的必要请求，其他规则全部继承。
