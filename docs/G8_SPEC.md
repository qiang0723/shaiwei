# G8 同风险产品比较执行规格 — g8-v1

冻结日：2026-07-16。产品篮子已于 2026-07-15 冻结，成员及 R1 替换规则见
`templates/fund_comparator.csv` 与 `docs/FUND_COMPARATOR_SPEC.md`。本规格在首个三年裁决计算前
冻结，禁止看结果后修改；任何改变必须升新版本，旧报告和旧规格哈希不得覆盖。

## 1. G8 回答的问题

G8 只回答：从冻结日起满三年后，筛微策略在承担与每只冻结产品相同的事前风险、扣除双方实际
发生的费用和税负后，是否稳定高于产品篮子中位数。它不回答哪只基金最好，也不允许用事后
最优波动窗口、融资杠杆、幸存者替换或缺失净值填充来改善结论。

## 2. 输入证据合同

- 策略列为实际账户或可逐笔复核的组合日总收益，已含现金、佣金、印花税、滑点和实际税负。
- 产品列固定为篮子中六条比较袖套，以原始 A 类代码作为稳定列名，使用法定披露的份额累计净值/分红构造日总收益；基金运作费
  已反映在净值内，申购和赎回费按实际持有金额、持有期和当时费率计入首尾现金流。
- 比较从 2026-07-15 之后的首个共同开放日开始。风险估计可读取比较窗前 60 个交易日作预热，
  但这些预热收益不进入三年业绩。
- 六只产品与策略必须使用唯一、递增的共同交易日；不得前向填充净值。三年窗至少 720 个共同
  日收益，任一产品有效风险覆盖率低于 95% 时失败即停，不得删除落后产品后继续。
- 产品清盘或净值不可比时只按已冻结 R1 从触发日向前接续：原始代码仍作为比较袖套列名，另存
  替代产品代码、生效日和来源的逐日谱系；保留原产品历史，不回填。

公募开放式基金净值应不晚于开放日次日披露，输入应以法定披露渠道为准：
https://www.csrc.gov.cn/csrc/c106256/c1653985/content.shtml 。

## 3. 事前成对风险归一化

对策略 `s` 与产品 `j`，先以 `t-60...t-1` 的日收益样本标准差计算年化波动率：

`sigma(i,t) = std(r(i,t-60:t-1), ddof=1) × sqrt(252)`

只使用 `t-1` 及以前信息。当天共同风险目标和权重为：

`target(j,t) = min(sigma(s,t), sigma(j,t))`

`w(s,j,t) = target(j,t) / sigma(s,t)`

`w(j,t) = target(j,t) / sigma(j,t)`

因此两边权重均不超过 1，不虚构融资杠杆。任一波动率低于 1% 年化时该日无效；未投入部分按
零日收益现金处理，避免三年后再挑选有利的现金利率源。归一化日收益为：

`r*(i,t) = w(i,t) × r(i,t)`

采用近期已实现波动率作下一期风险尺度，与波动管理组合使用滞后实现方差的原则一致；本项目只
用它做公平比较，不把波动择时收益冒充策略 alpha。方法参考：
https://www.nber.org/papers/w22208 。

## 4. 三年净超额与“稳定”的冻结定义

每个产品都单独与策略成对归一化。任一收益序列 `r` 的年化收益为：

`R_ann = product(1 + r) ** (252 / N) - 1`

产品 `j` 的税后净超额：

`E(j) = R_ann(strategy matched to j) - R_ann(product j matched to strategy)`

篮子主指标为六个 `E(j)` 的中位数。三年窗再按日历周年分成三个不重叠子期，各子期重复计算
六组净超额并取中位数。只有以下三项同时满足才为 `PASS`：

1. 三年篮子中位数净超额严格大于 0；
2. 六只产品中至少四只的三年净超额严格大于 0；
3. 三个年度子期中至少两个的篮子中位数净超额严格大于 0。

任一不满足即 `TRIGGER_G8`，执行 `docs/GATES.md` 规定的“财务上不成立，转纯学习仓位”。满三年
以前只能返回 `NOT_READY`，不得输出方向性 G8 结论。

## 5. 机器化与审计

- 配置：`config/settings.yaml` 的 `g8_evaluation`，所有阈值禁止散落在代码中。
- 计算器：`src/shaiwei/evaluation/g8.py`；拒绝缺失值、重复日期、非有限值、少于 -100% 的日收益、
  产品数不等于六、风险覆盖不足或任何大于 1 的风险权重。
- `make g8-spec` 只打印配置、产品代码、产品文件 SHA-256 和合成规格 SHA-256，不读取未来净值、
  不作提前裁决。
- 正式裁决必须把输入文件哈希、代码快照、产品文件哈希、规格哈希、逐产品结果和三个子期结果
  追加到不可覆盖实验账本；该写入器在真实三年数据形成前另行施工，不提前制造空结论。
