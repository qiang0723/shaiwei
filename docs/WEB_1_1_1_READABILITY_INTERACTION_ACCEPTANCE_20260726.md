# Web 1.1.1 易读与只读交互补正验收（2026-07-26）

## 1. 结论与授权边界

七类页面已完成默认主视图的技术字段降噪，并保留按需审计与只读下钻，结论为
`GO_LOCAL_READ_ONLY_REVIEW`。

本结论只表示中文业务表达、信息层级、只读交互、真实数据浏览器验收和本机服务隔离达到复核门；不表示
策略有效、因子准入、模型可生产，也不授权远程开放、写入、调参、重跑、交易、删除或导出原始数据。
本轮没有修改 API、`src/`、config、compose、模型、门禁、账本、生产数据或 scheduler。

## 2. 默认界面的表达裁决

用户先看到状态、日期、行动、结果和原因；哈希、快照 ID、模型/代码/数据身份、英文枚举、运行 ID、批次
ID、原始错误名和脱敏来源只在明确的“查看技术证据”或分节详情中出现。

| 改前主视图 | 改后主视图 | 审计保留方式 |
| --- | --- | --- |
| “数据快照已绑定”加一段哈希 | “数据证据已校验 / 已锁定” | 页首技术证据抽屉可展开、复制 |
| `PASS`、`WARN`、`NOT_DUE` 等英文枚举 | “通过”“需关注”“尚未到期”等中文语义 | `title` / `aria-label` 保留机器状态 |
| 模型、Qlib、代码与数据信息并列占据主区 | “四项研究身份已校验” | 技术标识按需展开 |
| 批次 ID、内容哈希、运行 ID、消息 ID | 中文数据源、批次序号、运行结论和故障概括 | 技术详情分节展示脱敏原值 |
| 哈希式实验 ID 直接作为目录首列 | “实验 1、实验 2……”稳定页内编号 | 原 ID 仅用于链接目标、辅助说明与详情技术证据 |
| 原始错误名直接进入告警正文 | 中文故障原因和影响 | “查看原始技术原因”折叠区 |

负面事实没有被隐藏或改判：“发现层拒绝”“方法已失效”“权威停止”“仅发现层”、通知失败后恢复、
数据证据缺口、`NOT_EVALUATED` 与短 FORWARD 样本仍在主视图明确出现。降噪只改变默认表达层，不改变
权威状态或查询数值。

## 4. 已实现的只读交互

交互全部复用现有只读查询，不虚构后端能力：

1. 全局证据日期选择与路由下钻保持同一 `as_of` 语义。
2. 页首“查看技术证据”抽屉按需显示身份、哈希、来源与复制入口，并解释用途。
3. 股票/信号支持搜索、业务筛选和行详情；技术哈希只在行详情内展开。
4. 因子支持目录筛选、严格同口径比较、详情和追加式准入历史。
5. 实验支持七项精确筛选、后端分页、可点击人类编号和类型化详情；不按表现排序。
6. 模拟组合支持区间切换、日期范围、账户日详情和交易/持仓证据下钻。
7. 系统运行支持故障通知详情；数据质量支持哨兵与批次技术详情。
8. 请求失败仍可安全重新读取查询，但没有生产重跑、修数或写入按钮。
