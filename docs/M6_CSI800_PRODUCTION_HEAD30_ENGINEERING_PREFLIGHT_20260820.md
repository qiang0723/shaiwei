# M6 生产 Head30 转换器结果盲工程预检

## 结论

`GO_PRE_EFFECT_ENGINEERING`。生产 `rank-head Top30` 等权全目标转换已经具备独立、可测试的 Qlib
适配器和机器协议合同；本结论不表示真实效果通过、50万元规模可行或生产获准。

## 已完成

- 新增确定性排序：分数降序、证券代码升序；缺失分数剔除，重复键、非有限值、截面不足和 `.BJ`
  均失败关闭，与生产信号选择语义一致。
- 新增完整目标数量计算：每次合法调仓按账户开盘价值和目标投资比例重算全部30只目标数量，不只
  更换落榜证券；先卖出非目标和超额数量，再按排名买入缺口。
- 10交易日节奏、T-1分数/T开盘、方向性涨跌停、Qlib合法数量舍入和交易所实际成交约束继续复用，
  不在转换器复制价格、费用或成交公式。
- 机器合同绑定 M6 封存输入、生产 selector、模拟执行器和历史对照策略；真实效果、Qlib数据、账本
  和生产权限默认为 false，`pending` 必须失败关闭。
- 一个新组合转换尝试的 family、首次效果读取时点、失败仍计数和统一实验账本已在协议中冻结。

## 机器测试

专项测试覆盖：

1. 原 G0 六窗/4窗/1.5倍成本公式与单变量合同；
2. 协议、权限、门槛或前序哈希漂移失败关闭；
3. 排序平局、缺失、重复、非有限值、截面不足和北交所拒绝；
4. 保留证券也按完整目标再平衡，而非只做成员替换；
5. 合成持仓从 `SH1/SH2` 正确卖出 `SH1`、保留 `SH2`、买入 `SH3`，非调仓日零订单。

首轮测试同时捕获已推送基础协议中的62字符错误 SHA。原协议未修改，hash addendum 绑定原协议
SHA、原错值和真实64字符SHA，并锁定问题、转换器、G0、权限、尝试数不变；全程未读取效果值。
