# P3 Web UI v1 安全补遗（2026-07-25）

## 1. 原因与时点

`p3-web-ui-v1` 于提交 `b75b4b3` 结果前冻结后、前端实现提交前，依赖审计发现
`react-router-dom=7.18.1` 落入 `GHSA-qwww-vcr4-c8h2` 的影响区间
`>=7.12.0,<8.3.0`。该问题只影响不稳定 RSC API；本项目没有使用 RSC，且 HTTP
边界仍为 GET/HEAD 只读，但 P3-1 不接受高危生产依赖告警。

官方修复版 `8.3.0` 在本次验收时尚未发布到 npm 注册表。npm 审计给出的当前可用
无告警版本为 `react-router-dom=7.11.0`；其 Node 要求为 `>=20`、React peer 要求为
`>=18`，与冻结的 Node 22 和 React 19 兼容。

## 2. 唯一变更

- `react-router-dom`：`7.18.1` → `7.11.0`。
- 同步重锁 `package-lock.json`，并要求生产依赖与全量依赖审计均为 0 漏洞。

除此之外，页面、查询契约、状态语义、只读边界、CSP、性能预算、响应式、可访问性、
Docker 隔离和所有验收门槛均保持 `p3-web-ui-v1` 原冻结值不变。本补遗不授权 RSC、
服务端 action、写接口或任何交易控制。

## 3. 失败条件

升级后若类型检查、单元测试、浏览器测试、CSP 或既有路由行为任一失败，则 P3-1
不得 GO；不得通过关闭审计、忽略高危项或放宽 HTTP/CSP 边界解决。
