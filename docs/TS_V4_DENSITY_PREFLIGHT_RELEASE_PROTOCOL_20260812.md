# TS-v4B 一次性结果盲密度预检 release

日期：2026-08-12（UTC+8）

状态：`FROZEN_BEFORE_REAL_PROFILE`

## 1. 本节点只回答一个问题

TS-v4A 已经把唯一变化轴冻结为上一完整周 VWAP 下方 1.5%、2.5%、3.5%、4.0% 四个回调深度。
本 release 只在 2019—2021 发现期判断：四臂各自是否拥有足够多且跨年分布不过度失衡的真实合法事件，
并且这些事件能否 100% 对齐冻结 Alpha158 缓存的键。它不回答哪个参数收益好，也不读取收益、
Alpha158 分数、H00906 点位或任何入场后路径。

唯一继续门是：至少一对相邻参数同时满足每臂不少于 30 个合法事件、20 个不同信号日，2019、2020、
2021 每年各不少于 5 个，Alpha158 事件键无重复且覆盖率为 100%。否则机械停止为
`STOP_NO_DENSE_PARAMETER_REGION`，画像后不得放宽门槛或补参数。

## 2. 时间、分母与状态机口径

为了形成 2019 年初的完整月周特征，可以读取 2016-01-01 起的结果前行情与参考字段；正式分母只取
2019-01-02 至 2021-12-31 发现期。按照 v4A 已冻结的最长退出时钟，发现期末最后 16 个官方上交所
信号日全部剔除，下一时间分区不得为发现期补结果；代码须把实际最后可用信号日写入报告。

四臂共用 v3 R4 已审计的市场、板块、月线、周线、恢复、失效和紧邻下一开盘口径，只把触达线替换为
`上一完整周复权 VWAP × (1−该臂回调深度)`。每个证券、计划周、参数臂仅保留首次合法恢复确认；结构
失效是吸收态。紧邻下一官方开盘必须仍在成员集合、复权因子一致、有正成交量、位于结构止损上方且
不高于冻结周 VWAP，止损距离必须严格位于 0%—15% 之间。失败开盘不延后重试。

## 3. 证据、尝试数与失败关闭

四个已提出参数永久计为四次策略尝试，即使某臂稀疏或失败也不能删除；本节点的真实画像和独立审计
各只能运行一次，策略效果尝试仍为 0。事件中间表可以在 Git 忽略目录保留证券身份以供独立复算，
对外报告只给每臂状态、日期和年度计数；所有产物禁止出现收益、盈亏、MAE/MFE、Sharpe、回撤、
Alpha158 分数或排名字段。

执行必须使用已经推送到 `origin/main`、内嵌相同 Git 身份的短命 Docker 镜像，`network_mode=none`，
不挂载 `.env` 或 secret，只给本 scope 输出目录写权限，不重启或修改生产 scheduler。缺文件、哈希不符、
字段越界、重复键、产物已存在或身份不一致均失败关闭，不以部分结果作策略判断。

## 4. 本次授权边界

本 release 授权协议/fixture 施工、唯一一次断网真实密度画像与一次独立审计；不授权收益、基准点位、
模型、预测、外网、provider、密钥、回测、模拟仓、Web或生产。即使密度门通过，也只允许另立效果
release；在 H00906 全收益谱系门完成前仍不能读取策略效果。

机器真身为 `config/ts_v4_density_preflight_release_v1.yaml`，其前置 v4A 文件保持不改写。
