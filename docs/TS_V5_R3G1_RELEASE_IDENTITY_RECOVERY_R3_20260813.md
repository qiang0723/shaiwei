# TS-v5 R3G-1 镜像身份 R3 恢复加注

R2 真实画像运行前核对发现：构建命令中的 40 位 Git 哈希由人工录入时有一位错误。错误镜像
`sha256:18c3174b...ddf4c`虽然成功构建，但从未启动容器进程，未读取行情或密度、未写画像/事件/审计、
未访问网络或密钥，因此没有消费 R2 唯一真实画像与独立审计次数。

R3 只加固发布身份：Make 构建入口必须自动比较请求哈希、本地 `HEAD` 和本地 `origin/main` 跟踪引用；
运行时必须校验镜像内受控文件 manifest。之后按新的已推送 Git 身份重建镜像。候选、六机制、431 点、
2021—2026 三段时间角色、数据输入、参数、门槛、选择逻辑和结果权限全部不变。错误镜像永久标为
`PROVISIONAL_NEVER_RUN`，不得用于任何画像或裁决。
