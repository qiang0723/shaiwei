# 市场趋势、行业强度与涨停情绪能力提案

- 日期：2026-08-25（UTC+8）
- 状态：`PROPOSED_NOT_AUTHORIZED`
- 性质：外部页面只读评估后的结果盲能力提案
- 生产授权：无

## 1. 结论与路线位置

对三份截至2026-08-24的本地HTML快照完成只读评估后，裁决为“研究机制和页面结构有用，原始页面及
内嵌数据不可直接进入筛微”。三类能力按研究价值排序：

1. 行业相对强度：优先服务TS/TP-F的“强板块→强股票”机制；
2. 全市场趋势与宽度：服务市场状态、风险许可和Web总览；
3. 涨停情绪：只作拥挤、过热和风险辅助，不作直接买入信号。

本提案不插入当前主线。顺序保持`R2D生产提升协议→G1阳性对照→TP-F-0B结果盲预检`。TP-F-0B优先
复用项目内PIT申万行业与自身行情构造派生行业篮子；只有现有数据无法满足冻结问题，才另立外部数据
源合同。涨停情绪不得阻塞TP-F首版。

## 2. 三个候选只读合同

### 2.1 `market_regime_snapshot`

候选字段包括市场上涨/下跌/平盘家数、站上MA20/MA60比例、强趋势比例、20日收益分布、成交额及
时间序列。权威实现必须使用筛微自身登记行情和股票池，`.BJ`为0，ST须单独分层，不把当前全市场
快照静默混入中证800或未来科技池。

该快照只提供市场状态和风险背景；任何“允许交易/禁止交易”规则仍须另立结果前协议，不能从单日
页面观察直接生成生产门槛。

### 2.2 `sector_strength_snapshot`

候选字段包括PIT行业身份、5/20/60日相对大类指数收益、行业MA20状态、成交额脉冲、排名变化、成分
上涨宽度、行业内强股和证据覆盖率。TS/TP-F首选项目内PIT申万一级行业派生篮子，不能把第三方行业
指数或当前成分冒充既有冻结口径。

外部页面的90个行业指数本身可作为公式与交互参考，但成分总数5,550只中同日快照只覆盖1,577只，
覆盖率约28.4%；90个行业中47个为零快照、23个部分覆盖。故其指数RS可以继续核源，行业宽度和等权
涨跌代理当前为`NOT_TRUSTED_FOR_RESEARCH_VERDICT`。未来门必须逐行业输出成分覆盖、PIT生效日、基准
身份和源版本，并对覆盖不足失败关闭。

### 2.3 `limit_up_sentiment_snapshot`

候选字段包括涨停数、首板/连板分层、最高板、早封与竞价封板数量、封单与最大封单、封板留存、有限
样本晋级率、涨停原因关键词和炸板率。当前页面内部46只涨停、10只连板、40只早封、9只竞价封板可
复算一致，但只有30日天梯、无炸板池，晋级率也不是全市场分母；封板留存均低于8%、均值约1.6%，
还须核验接口字段单位与经济含义。

在补齐涨停池/炸板池、完整前一日候选分母、ST政策、历史版本和至少跨多个市场阶段的覆盖前，只能
作为`OBSERVATION_ONLY`风险辅助，不得进入因子准入、选股、买点、模拟仓或生产。

## 3. 数据、合规与安全边界

- 不把三份HTML、内嵌5,520只股票横截面、第三方ECharts包或本地绝对路径提交进仓库；
- 不把第三方API描述视为已授权数据源；若未来采集，须先确认使用权限、版本、限速、修订与PIT语义；
- 不复用页面中的`.BJ`和ST混合全市场口径；筛微现有禁北交所与分层规则优先；
- 不从单日或82日/30日短窗口选择交易阈值，不用页面榜单作为证券推荐；
- 前端只消费后台原子只读合同，不解析HTML、扫描外部文件或复制指标公式。

## 4. 最小后继与停止线

当前代码、配置、数据源、Web、模型、策略、账本和生产均不改。未来只有满足路线触发器后，才允许
按以下顺序逐项申请：

1. TP-F-0B核对项目内市场/行业字段、PIT覆盖和身份去重；
2. 若通过，先冻结`sector_strength_snapshot`最小Schema与覆盖门；
3. `market_regime_snapshot`作为独立市场背景合同，不与首个TP-F候选同时改变；
4. `limit_up_sentiment_snapshot`放在TP-F首版之后另立数据门；
5. 后台权威合同稳定后，Web再借鉴气泡、热力带、宽度与下钻交互，不从页面反向定义口径。

任何数据缺口只能返回`NOT_READY`、`NOT_EVALUATED`或`BLOCKED_DATA_QUALITY`，不得用页面快照、当前
成分、人工补数或第三方榜单填补。
