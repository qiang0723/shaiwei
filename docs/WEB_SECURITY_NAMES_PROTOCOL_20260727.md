# Web 模拟仓中文简称展示协议

> 冻结日期：2026-07-27（Asia/Shanghai）
>
> 协议：`p3-web-security-names-v1`
>
> 状态：`FROZEN_BEFORE_IMPLEMENTATION`

## 目标

在模拟组合“实际持仓”表中把中文证券简称作为第一识别信息，股票代码继续作为第二行审计标识。名称只
用于可读性，不改变账户、模型、信号、排序、交易、估值或判决。

## 数据口径

主来源为已登记并通过内容哈希复核的 `tushare.namechange`，按账户估值日解析最新有效名称区间；同一
起始日出现多个不同名称时 fail closed。只有没有有效历史区间时才使用 `stock_basic` 当前简称，并把
来源状态标为 `WARN`，不得把当前简称静默包装成历史 PIT 名称。两处都缺失时返回空名称与
`NOT_READY`，页面显示“名称待同步”，不得隐藏整只持仓或自行联网补名。

冻结后源审计发现 `stock_basic` 含 1 条上交所 `T` 前缀测试证券 `T600018.SH`，它不是 A 股公司。
投影器只对 `T` + 6 位代码的沪深交易所测试证券做“排除并计数”；其他未知代码格式仍 fail closed，
不得借此放宽 A 股范围。

原始 Parquet 不挂载给常驻 Web。一次性无凭据、断网投影器从 ingest ledger 定位并复核原始批次，生成
内容寻址的 `data/web/security_names/<sha256>/bundle.json` 和原子 `current.json` 指针。Web 查询把指针
及 bundle 哈希绑定进原子 snapshot，查询过程中任何变化均重试后 fail closed。

## 展示与验收

- 桌面和移动端均显示“中文简称 / 股票代码”，不增加一列造成表格进一步横向膨胀；
- 时点名称、基础信息回退、缺失三种状态必须可区分；
- `.BJ` 不进入名称投影，若任何 Web 响应出现 `.BJ` 仍整体失败；
- 两账户、历史 `as_of`、键盘/回流/无障碍、CSP 和只读边界保持不变；
- 只重建隔离 Web 服务，不重启 scheduler，也不改变已暂存的 Top20 scheduler 候选镜像。
