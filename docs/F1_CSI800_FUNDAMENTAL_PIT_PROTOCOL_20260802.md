# F1-0 中证800基本面 PIT 数据与特征可施工性协议（结果前冻结）

冻结日期：2026-08-02（UTC+8）  
协议 ID：`f1-csi800-fundamental-pit-data-feature-gate-v1`

## 1. 要回答的问题

现有中证800生产基线主要使用 Alpha158 量价特征。本阶段只回答：仓库内已经登记的财务三表真身，
能否在严格 PIT、修订、成分和确定性约束下，构造一组可供后续独立因子研究使用的基本面特征。

`GO` 只表示数据和公式工程可施工，不表示因子有效、模型提升或可以进入生产。任何收益、标签、IC、
G1、模型、回测、信号、持仓和生产接入均不在本阶段授权内。

## 2. 冻结输入与研究边界

- 股票池固定为既有 `csi800-pit-v1` / `000906.SH`，不新建股票池，不改变生产成分口径。
- 时间范围固定为 2016-01-01 至 2026-07-31；质量裁决从 2018-05-02 起，按每月最后一个开市日评价。
- 只读取 `ledger/ingest_batches.csv` 登记且哈希、行数可复核的本地不可变批次。
- 数据源只限交易日历、中证800月度成分和 income/balancesheet/cashflow 的普通与 VIP 批次。
- 禁止联网补采、改写原始批次或账本；发现缺口即如实 `NO-GO`，另立恢复任务。
- 北交所后缀 `.BJ` 必须为 0。

## 3. PIT 与修订规则

只用年末为 `1231` 的年度口径，避免把不同累计季度直接混为同一截面。每条报表以
`f_ann_date` 后第一个开市日才可用；同一证券、报告期只从届时已可见的版本中取最新公告，公告日相同
时沿用既有 `report_type=1` 优先于 `5`、`update_flag` 降序的冻结规则。

三表组合必须精确匹配 `ts_code + end_date`。跨表特征的可用日取全部组件可用日的最大值，禁止用一张
表的新报告期和另一张表的旧报告期拼接。`fina_indicator` 因缺少本协议要求的完整版本语义，继续禁用。

## 4. 首批六项无方向特征

本阶段仅验证以下原始公式能否被 PIT 构造，不冻结经济方向，不做 winsorize、中性化或排名：

1. 归母净利润 / 总资产；
2. 营业利润 / 营业总收入；
3. 经营现金流 / 总资产；
4. 总负债 / 总资产；
5. 货币资金 / 总资产；
6. （归母净利润 - 经营现金流）/ 总资产。

总资产与营业总收入作为分母时必须有限且严格大于 0；非有限结果置空，不用常数填充。字段、公式和
分母规则的机器真身见 `config/f1_csi800_fundamental_pit_v1.yaml`。

## 5. 结果前硬门

- 八类冻结源均存在，当前最新请求批次逐个通过文件存在、Parquet 行数和 SHA-256 校验；
- 必需字段齐全，同一源身份没有字段值冲突；研究范围内交易日历可闭合；
- 质量期至少 90 个形成日，每个形成日中证800可用成员数为 700—900，`.BJ=0`；
- 跨表混期、使用未来可用报表均为 0；
- 六项特征各自在全部成员形成日上的有效覆盖率不低于 90%，单个形成日最差覆盖率不低于 80%。

任一硬门失败即 `NO_GO_F1_FUNDAMENTAL_PIT_DATA_FEATURE_GATE`，不因失败调整日期、阈值、公式、
分母或成分。全部通过才可记 `GO_F1_FUNDAMENTAL_PIT_DATA_FEATURE_GATE_ONLY`。

## 6. 产物、复跑与权限

真实特征值和质量报告只写 Git 忽略的项目内 `data/research/f1_csi800_fundamental_pit_v1/`；Git 只提交
协议、代码、fixture/测试、脱敏汇总 manifest 和验收文档。相同冻结输入必须逐内容复跑一致。

即使数据门 `GO`，后续也必须另立结果前协议，冻结方向、可比基线、残差化、窗口、成本、多重检验和
G1 才能看效果。本任务不读取 `.env`，不调用 DeepSeek/Tushare，不修改 scheduler、生产镜像、
Alpha158、Top20 发布、模拟仓、Web、门禁或生产数据。
