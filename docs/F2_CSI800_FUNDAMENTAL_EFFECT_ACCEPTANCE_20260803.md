## 1. 权威结论

F2-1 已按结果前冻结协议完成，权威裁决为 **REJECT**：六个预注册动态基本面候选中，五个通过固定

组合效果前停止。正式因子库插入 0 个，生产授权为 `none`。

这不是 F2-0R 数据门失效，也不是执行故障。正确表述是：六项连续年度基本面变化可以按严格 PIT
口径稳定构造，其中五项在发现期呈现预注册方向的信息；但以行业、市值和 Alpha158 残差为增量口径，
并以 10% 权重加入既有 Alpha158 组合后，没有形成同时满足窗口稳定性、净 ICIR/净超额增量、成本、
DSR 与 HAC 显著性的可准入价值。
